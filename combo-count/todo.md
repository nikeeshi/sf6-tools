# 残っている検証項目

考察の中で出てきた「まだ測っていないこと」を集めたもの。詳しい経緯は各キャラの `analysis.md` を参照。

## システム全体

| 項目                         | 手順・状況                                                                                                                                                                                                                                                                                                                                                             |
| ---------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **カウンターで値が変わるか** | DI では**やられ状況**で変わることが判明(壁張り付き 0、パニッシュカウンターの膝崩れ 1)。ただし壁張り付きはガードでもヒットでも 0 なので、ガード・ヒットの別では変わらない。通常技については、**変わるとしても 5強P だけという見込み**(カウンターでやられ状況が変わる技だから)。始動値が判明済みの技(弱P か 中P、どちらも 1)をパニッシュカウンターで当て直せば裏が取れる |
| 追撃不可ヒットになる理由     | 未解明。同じ技が別のカウントで追撃可になるかを見れば切り分けられる                                                                                                                                                                                                                                                                                                     |
| 上限値の最大は 99 か         | 仮説。100 以上の上限値を持つ技が出れば崩れる                                                                                                                                                                                                                                                                                                                           |
| 始動値の下限は 0 か          | 仮説。0 未満の始動技が出れば崩れる                                                                                                                                                                                                                                                                                                                                     |

## ドライブラッシュ周り(未着手)

既知は **ラッシュ通常技(特殊技を含む)の加算値が 0** ということだけ。ラッシュ版と原技のパラメータ関係は未確認。

判定は加算前と定義しているので、**加算値 0 はその技自身が当たるかどうかには効かない**。それでも「ラッシュを入れると当たるようになる技がある」なら、**ラッシュ版は上限値そのものが高い**ということになる。ここを実測で確かめたい。

| 項目                                   | 手順                                                                                                        |
| -------------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| ~~ラッシュ版の上限値が原技より高いか~~ | **実験36 で確認済み**。ラッシュ強Kが 4 で、原技の 5強K(1段目 0 / 2段目 1)より高い。他の技でも同様かは未確認 |
| ラッシュ通常技の加算値が本当に 0 か    | `極太ビーム → ラッシュ通常技 → 上限値 0 の技`。カウントが動かないなら当たる(空中極太と同じ手)               |
| パリィラッシュとキャンセルラッシュの差 | 同じ技で両方測って比べる                                                                                    |
| ラッシュ版の始動値                     | 未着手                                                                                                      |

### 追撃猶予

6強P(空中 8F / 地上 5F)と Lv2ビーム(27F)以外すべて未測定。極太ビーム、Lv3ビーム、Lv1ビーム、強サンライズなど。**イングリッドはダウン無敵の例外が多いので、ダウン時間からの計算に頼らず個別に測ること。**

見た目の判断では、**大足・ルミナスアッパーの1段目・4中K のターゲットコンボ・必殺技すべて**がダウン無敵 33F ではなさそう。ここは特に個別測定が要る。
