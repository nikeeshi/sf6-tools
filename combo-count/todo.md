## システム全体

| 項目                         | 手順・状況                                                                                                                                                                                                                                                                                                                                                             |
| ---------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **カウンターで値が変わるか** | DI では**やられ状況**で変わることが判明(壁張り付き 0、パニッシュカウンターの膝崩れ 1)。ただし壁張り付きはガードでもヒットでも 0 なので、ガード・ヒットの別では変わらない。通常技については、**変わるとしても 5強P だけという見込み**(カウンターでやられ状況が変わる技だから)。始動値が判明済みの技(弱P か 中P、どちらも 1)をパニッシュカウンターで当て直せば裏が取れる |

## ドライブラッシュ周り(未着手)

既知は **ラッシュ通常技(特殊技を含む)の加算値が 0** ということだけ。ラッシュ版と原技のパラメータ関係は未確認。

判定は加算前と定義しているので、**加算値 0 はその技自身が当たるかどうかには効かない**。それでも「ラッシュを入れると当たるようになる技がある」なら、**ラッシュ版は上限値そのものが高い**ということになる。ここを実測で確かめたい。

| 項目                                   | 手順                                                                                          |
| -------------------------------------- | --------------------------------------------------------------------------------------------- |
| ~~ラッシュ版の上限値が原技より高いか~~ | **確認済み**。強K(2段目) 1 → 4、ルミナスアッパー 0 → 3、中K 0 → 3 で、いずれも **+3**         |
| **差が一律 +3 か**                     | 3 技で +3。原技の値が違うのに差が揃っているので濃厚だが、まだ 3 技                            |
| ラッシュ通常技の加算値が本当に 0 か    | `極太ビーム → ラッシュ通常技 → 上限値 0 の技`。カウントが動かないなら当たる(空中極太と同じ手) |
| パリィラッシュとキャンセルラッシュの差 | 同じ技で両方測って比べる                                                                      |

## イングリッド

### SA2 をブリッジに使う(未実施)

SA2 は発動してから弾が着弾するまで時間差がある。先に撃っておけば **発生を入力から切り離した追撃**として置けるので、追撃猶予が短くて後が続かない技でもコンボを無理やり伸ばせる。プローブ(上限値で切る役)ではなく**ブリッジ**としての用途。

**X の後に直接ビームが繋がるなら SA2 は要らない。**校正定数を背負わずに済むので、猶予が足りない技にだけ使う。

校正: `DI壁張り付き → SA2の弾 → 読み出し` で `加算値(SA2)` を先に出す。下の2プロトコルに共通で乗る定数なので、一度測れば両方に効く。

| 目的       | 手順                                              | 読み出せる値              |
| ---------- | ------------------------------------------------- | ------------------------- |
| **加算値** | `DI壁張り付き(始動値0) → X → SA2の弾 → 読み出し`  | `加算値(X) + 加算値(SA2)` |
| **始動値** | `最低空ボルシチのザンギに X → SA2の弾 → 読み出し` | `始動値(X) + 加算値(SA2)` |

始動側で DI ではなく空中の相手を的にするのは、X 自身を始動技にする必要があるため。加算値側で DI 壁張り付きを使うのは、ビーム始動だと浮きが大きすぎて当てにくい技があるため。

#### 読み出しはビーム連打より探索が安い

最後をビーム連打の本数で読むと1実験あたり100発近くになる。ビーム単発は上限値 99 なので当たり外れの1ビットとしては何も切れず、連打して数えるしかないため。代わりに:

```
X → SA2の弾 → 極太ビーム × j → 弱サンライズ(上限値10)
```

として**当たる最大の j** を探す。ビームは「届かせる役」と「値をずらす役」に回し、切るのは上限値 10 のプローブ。0〜10 に収まる限り二分探索で数回で済む。範囲を外れたと分かったときだけ連打に落とす。

#### 的: ザンギの最低空ボルシチ

**投げすかりモーションが出るので必ずパニッシュカウンターになる。**したがってここで得られるのは**パニカン始動値**で、DI を壁張り付き/パニカンの2行に分けているのと同じく、やられ状況ごとの別の値として記録する。

パニカンでやられ状況が変わらない技なら通常ヒットと同じ値になる。実例として、実験31(ラシード = パニカン)の弱P と実験30(非パニカン)の弱P がどちらも 1 で一致している。変わる技(強P の錐揉み)は通常ヒット始動値の入り口が別途要るので、測定時に**通常ヒットのやられと見た目が同じか**を1回見て分類しておく。

**高さが低いので、ラシードの空中移動技では届かなかった 下段系(2弱K/2中K/大足)と 6中P がここで開く。**ラシード法の置き換えではなく、守備範囲の違う別の的として両方使う。

対照として**弱P(既知の始動値 1)を最低空ボルシチに当てて 1 が出るか**を1回取る。的を入れ替えても同じ値が出れば手法の裏付けになる。

#### 先に潰す前提

- **SA2 の弾は3〜5発の多段。**ビームのように全段/0段の2択なのか、SA1 のようにカス当たりするのか未確認。バラけて落ちるなら「閾値の違う関門が順に並んだメーター」として使えるので、その場合は1回のコンボで区間が読める。加算が1発ごとか1キャストごとかも同時に見る。
- **9通り(位置3か所 × 弾数3通り)でパラメータが共通か。**位置ごとに加算値が違うと校正を3回やることになる。位置は落下タイミングの選択肢でもあるので、猶予合わせにはむしろ効く。
