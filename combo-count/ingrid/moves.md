# イングリッド 技リスト

コンボカウント測定の対象一覧。テンキー表記は move-db の id スラグ規約に合わせる。

## 表記の読み方

- しゃがみ = `2`。「屈」とも言う。
- 弱/中/強 = `L`/`M`/`H`。「2中P」と「2MP」は同じもの。
- 「立ち」は省略することがある(「中P」= 立ち中P = `5MP`)。

## 必殺技

### フレア系(ビーム)

**サンフレア = 地上から出すビーム、ソーラーフレア = 空中から出すビーム**。どちらも強度ごとの役割は同じ。

| 強度 | 役割                                                |
| ---- | --------------------------------------------------- |
| 弱   | サンスタックを貯める                                |
| 中   | サンスタック消費なしのビーム(= Lv1)                 |
| 強   | サンスタックを消費するビーム(Lv1〜Lv3)              |
| OD   | サンスタックを消費しつつ1段階性能を上げる(Lv1〜Lv3) |

入力は弱/中/強だが、出るモーションは 弱 / Lv1〜Lv3 で決まる。公式フレーム表もボタンではなく Lv で命名しているので、技名はそちらに合わせる。**サンスタックが 0 のときは中と強で同じものが出る**(どちらも Lv1)。

**OD は同じ Lv 表記でも性能が 1 段階上**。これは**ゲーム内のキャラクターチュートリアルに明記されている**。したがって性能は 4 段階で、`OD(Lv3)` だけがどの強版とも一致しない最上位。公式フレーム表の数値とも一致する:

| 性能段階 | 該当する技    | 発生 | 硬直 | ダメージ | ヒット数 |
| -------- | ------------- | ---- | ---- | -------- | -------- |
| 1        | Lv1           | 21   | 21   | 900      |          |
| 2        | Lv2 = OD(Lv1) | 18   | 14   | 1100     |          |
| 3        | Lv3 = OD(Lv2) | 18   | 14   | 1350     | 3        |
| 4        | OD(Lv3)       | 18   | 11   | 1800     | 4        |

同性能どうしの違いは OD 必殺技であること(SA2 キャンセルが可能)だけで、吹っ飛び方・ダメージ・フレームは同じ。

#### セリフで撃った Lv を判別する

| Lv  | 通常版     | OD版         |
| --- | ---------- | ------------ |
| 1   | きらり     | うけよ       |
| 2   | むぎゅっと | 貫け         |
| 3   | かがやけ   | おしおきじゃ |

性能段階に直すと 1段階目=きらり、2段階目=むぎゅっと/うけよ、3段階目=かがやけ/貫け、4段階目=おしおきじゃ(極太)。

実験中に狙った Lv が出ているかを耳で確認できる。たとえば 0ストックで OD を連打するなら毎回「うけよ」が鳴るはずで、「きらり」が混じっていれば性能1段階目を撃ってしまっている。

測定上の含意: ビーム6種を個別に測る必要はなく、**性能4段階の4通りを測ればよい**。`Lv2` と `OD(Lv1)` はコンボカウント値も一致するという仮説が立つ(一致しなければそれ自体が発見)。

| 技名                      | 別名       | 備考                       |
| ------------------------- | ---------- | -------------------------- |
| 弱 サンフレア             |            | サンスタックを貯める       |
| サンフレア(Lv1〜3)        |            |                            |
| OD サンフレア(Lv1〜2)     |            |                            |
| OD サンフレア(Lv3)        | 極太ビーム | コンボカウント測定の目盛り |
| 弱ソーラーフレア          |            | サンスタックを貯める       |
| ソーラーフレア(Lv1〜3)    |            |                            |

### サンシュート(通称: 弾)

OD/通常 × 弱/中/強 × 非ホールド/ホールド で 12 種あるが、**コンボに使うのは強弾か OD強弾くらい**なので他は気にしなくてよい。ホールドの有無は設置した後の弾の飛翔速度が変わるだけで、コンボでは設置までで当てるため影響しない(弾始動の場合も弾は弾なので変わらない)。

| 技名             | 別名   |
| ---------------- | ------ |
| 強サンシュート   | 強弾   |
| OD強サンシュート | OD強弾 |

| 技名         | 別名     | 内容                                                                                                 | 上限値の見込み |
| ------------ | -------- | ---------------------------------------------------------------------------------------------------- | -------------- |
| 弱サンライズ | 弱ライズ | その場で蹴り上げ一回転する対空攻撃                                                                   | 高そう         |
| 中サンライズ | 中ライズ | 前にスピンしてから蹴り上げ一回転。最初のスピンを当てるのがちょいムズ                                 | 高め           |
| 強サンライズ | 強ライズ | 発生がとても遅い代わりに、浮かせた後さらに空中攻撃を当てられる。通常は J中P かソーラーフレアを当てる | 低め           |

### サンバニッシュ(通称: バニ)

相手の位置にテレポートして攻撃する技。

| 技名                 | 別名          | 内容                                                                                                                       |
| -------------------- | ------------- | -------------------------------------------------------------------------------------------------------------------------- |
| サンバニッシュ(前方) | 前バニ        | 〆技。Lv3 以上のビームを当てた後に繋がるくらいの発生                                                                       |
| サンバニッシュ(上方) | 上バニ / ケツ | 極太ビーム(性能4段階目)を当てた後に繋がり、そこから中ライズまで入る。中ライズより発生の速い技(SA1、弱ライズなど)も当然入る |
| サンバニッシュ(後方) | 後ろバニ      | テレポートで逃げる技                                                                                                       |

## スーパーアーツ

| 技名               | 発生 | 内容                                                                                   |
| ------------------ | ---- | -------------------------------------------------------------------------------------- |
| SA1 サンシャイン   | 11   | 昇竜系                                                                                 |
| SA2 サンオーダー   | ※    | 3〜5発の弾を降らせる。位置が3か所選べて計9通り。位置によって降ってくる弾の発生が変わる |
| SA3 コズミックレイ | 20   | サーチしてその位置に弾を出す                                                           |

SA1 と SA2 は**ホールドでサンスタックを使うかどうかを選べる**(公式フレーム表の Lv1〜Lv3 はこれ)。

- **SA1**: Lv で変わるのは威力と起き攻め状況だけなので、コンボカウントの測定上は区別しなくてよい。
- **SA2**: Lv で弾の数が変わる。位置3か所 × 弾数3通りで計9通り。

SA2 のせいでコンボルートが無限になっている(整理はおいおい)。

**SA1 は発生 11F でイングリッドの追撃技のうち最速クラス**。「発生が間に合わず当たらない」交絡が最も小さいので、カウント測定のプローブ技に向く。

## 追撃猶予(実測)

その技を当てた後、**発生何Fまでの技なら追撃が間に合うか**。相手がダウン無敵に入るまでの猶予。公式フレーム表には無い実測値。

猶予が分かっていれば「当たらない」の原因を機械的に切り分けられる。**発生が猶予内なのに当たらないならカウント超過**、猶予を超えているなら間に合っていないだけ。ただし飛び道具は判定が出てから相手に届くまでの飛翔時間が上乗せされるので、発生Fだけでは判断できない。

ダウン無敵は 33F が標準なので `追撃猶予 = ダウン時間 − 33F` になるはずだが、**イングリッドは例外が多いのでこの計算に頼れない。技ごとに個別に測ること。**

| 技                           | 追撃猶予 | ダウン時間 |
| ---------------------------- | -------- | ---------- |
| 6強P(空中の相手に当てた場合) | 8F       | 41F        |
| 6強P(地上の相手に当てた場合) | 5F       | (+38F)     |
| Lv2ビーム(性能2段階目)       | 27F      | (60F)      |
| 極太ビーム(ODLv3)            | 未測定   |            |
| Lv3ビーム(性能3段階目)       | 未測定   |            |
| Lv1ビーム(性能1段階目)       | 未測定   |            |
| 強サンライズ                 | 未測定   |            |

6強P の猶予が 8F しかないことは、**6強P からソーラーフレアしか繋がらない**ことと噛み合う。空中極太ビームの発生は 18F でリンクでは間に合わず、繋がるのはキャンセルだから。

地上の相手に当てた場合は猶予 5F で、弱攻撃が追撃不可ヒットになる。

## 測定候補として拾える観測

- 極太ビーム → 上バニ → 中ライズ が繋がる。
- Lv3 以上のビーム → 前バニ が繋がる。

いずれも「発生が間に合うか」の話として語られているため、カウント超過とは切り分けが要る。記録に落とすときは [records.md](records.md) 側で実測として取り直す。
