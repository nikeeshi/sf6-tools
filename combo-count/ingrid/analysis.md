# イングリッド コンボカウント考察

観測は [records.md](records.md)、技リストは [moves.md](moves.md)。**このファイルの内容は推定であり、実験が増えれば覆る**。根拠は必ず実験番号で示す。

最終更新: 2026-07-28

## 喰らい方と測定基準

実験3(極太1回 = カウント0)と実験5(極太2回 = カウント1)で、**同じ技**が「当たる(追撃不可)」→「当たらない」に変わった(弱・中・強P)。同一技の比較なので当たり判定やリーチでは説明できない。したがって:

| 喰らい方           | 分かっていること                         |
| ------------------ | ---------------------------------------- |
| **当たらない**     | **カウント超過**(確定)                   |
| **追撃不可ヒット** | カウントは通過している(当たっているため) |
| **追撃可ヒット**   | カウント通過 + 空中やられ継続            |

**上限値の測定は「当たるか当たらないか」で判定する。** 当たった時点でカウントは通過しているので、追撃可否は上限値の判定に使わない。

**未解明: 追撃不可ヒットになる理由。** 「その技が空中やられを継続させない性質を持つ」という解釈はありうるが確認していない。同じ技が別のカウントで追撃可になるかどうかを見れば切り分けられる。

## 極太ビームは目盛りとして直読みできる

極太ビーム(ODLv3)は始動値 0・加算値 1(実験1 の正規化)なので、**極太 N 回で カウント = N-1** をそのまま作れる。実験3 がカウント 0、実験5 がカウント 1。

Lv3ビームを目盛りにする場合は始動値が 2 なので、**N 回で カウント = N+1**。

## 2つのビームは始動値だけが違う

実験7(OD始動 → Lv3ビーム連打で100発)と実験8(Lv3始動 → 99発)から:

- 実験7: Lv3ビームの k 発目が見るカウントは `k-1`。100発目が `99 ≤ 上限値`、101発目が `100 > 上限値` → **上限値(Lv3ビーム) = 99**。極太と同じ。
- 実験8: k 発目(k≥2)が見るカウントは `S3 + (k-2)`。99発目が `S3+97 ≤ 99`、100発目が `S3+98 > 99` → **S3 = 2**。

つまり**極太ビームと Lv3ビームは加算値も上限値も同じで、違うのは始動値だけ**(0 と 2)。

なお **「性能段階が1つ下がるごとに始動値 +2」という規則ではない**。それなら性能2段階目は 4 になるはずだが、実験14・実験15 から `始動値(Lv2ビーム) ≤ 2` で、性能3段階目と同じかそれより低い。2段階分の関係を線形に外挿してはいけない。

この「**始動値の差は加算値2ビーム分**」という言い方は単位の取り方に依存しない。仮に加算値が内部で 2 でも `始動値差 = 4 = 2×2` で成り立つので、正規化の選択に巻き込まれない表現になっている。

### Lv2ビームの始動値は連打では測れない

性能2段階目は **0ストックで OD版を撃つ**と出せる(OD(Lv1) = 性能2段階目)。0ストックなら消費するものが無くスタックは 0 のままなので、弱版を挟まない限り連打できる。これで実験1・実験8 と同じ手が使えるはずだった。

しかし実験14 で **Lv2ビーム始動から Lv2ビームが当たらない**。連打が成立しないので、この手順で始動値を測ることはできない。

実験14 で使ったのは 0ストックの OD版(= OD Lv1、性能2段階目)。OD 入力である以上スタックは動かず、2発目も同じ性能2段階目になる。

**そして原因が分からない。** 実験15 で大足の上限値が 2 と確定したので、実験14 から `始動値(Lv2ビーム) ≤ 2`。もし上限値が他のビームと同じ 99 なら `2 ≤ 99` で当たるはずで、当たらない理由がない。

したがって残る可能性は **上限値(Lv2ビーム)だけが極端に低い(2未満)** か、**カウント以外の原因** かの二択。性能3段階目・4段階目がどちらも 99 であることを考えると前者は不自然で、**Lv2ビームの浮きが小さく発生18Fが間に合っていない**線が濃い。

### カウントか発生かを切り分ける実験(未実施)

**プローブに使えるのは SA1 と SA3 だけ。** 上限値 99 と分かっているビームは極太(性能4段階目)と Lv3ビーム(性能3段階目)で、どちらも2ストック必要。Lv2ビームを撃った直後は 0 ストックなので撃てるのは性能1〜2段階目だけで、**上限値が未知のビームしか出せない**。SA1・SA3 はサンスタックを必要としないので使える。

| 技     | 上限値 | 発生 |
| ------ | ------ | ---- |
| SA1    | 99     | 11   |
| ビーム | 不明   | 18   |
| SA3    | 99     | 20   |

**発生Fだけで判断してはいけない。** Lv2ビーム後は発生27Fまでの技が繋がる(実験14)ので、発生18F のビームは 9F も余裕がある計算になる。それでも当たらない。

発生Fは攻撃判定が出るフレームであって相手に届くフレームではない。**ビームは飛び道具なので、判定が出てから相手の位置まで飛翔する時間が上乗せされる**(当てるたびに相手を押し出すなら距離も伸びる)。一方 **SA3 はサーチして相手の位置に弾を出す技**なので飛翔時間がゼロで、20F がそのまま到達フレーム。SA1 も昇竜系で目の前に出るので同様。

つまり「発生27Fまで繋がる」が成り立つのは**相手のいる場所に判定が出る技**であって、ビームは例外。18F のビームが当たらず 20F の SA3 が当たっても矛盾しない。

これは極太で101発繋がったこととも整合する。極太は浮きが大きく滞空が長いので、飛翔時間を払う余裕がある。

SA1 と SA3 は上限値が同じなのでカウントでは区別できず、発生だけが違う。Lv2ビーム始動で両者を試すと:

- **両方当たる**(予測) → ビームが当たらない理由はカウントではない。飛翔時間で説明がつき、カウントモデルは無傷。上限値(Lv2ビーム)は未知のまま残る。
- **SA1 が当たり SA3 が当たらない** → 発生27Fまで繋がるという観測と噛み合わないので、猶予の測り方かモデルのどこかがずれている。
- **両方当たらない** → 上限値 99 が当たらないのにカウント 2 の大足が当たったことになり、カウントでは説明できない。別の機構を疑う。

この手は Lv2ビームだけの話に留まらない。実験2(強サンライズ始動)で残っているリーチ由来の疑いにも、同じく SA1 と SA3 の対で使える。

## 6強P始動は極太始動と同じかそれより低い

実験6 の始動技は 6強P で、テスト技が見るカウントは `始動値(6強P) + 加算値(ODソーラーフレアLv3)`。結果が実験3(カウント 0)と全項目一致し、上限値 0 の技が当たっているので**この和は 0 以下**。ソーラーフレアの加算値がサンフレアと同じ 1 なら **始動値(6強P) ≤ −1** となり、極太始動より低いカウントを作れる始動技ということになる。

## ビームは多段技だが1キャスト単位で扱ってよい

**ODLv3ビームは4ヒット、Lv3ビームは3ヒット**の多段技。加算がヒットごとなら上限値は極太で396〜400、Lv3ビームで297〜300あたりに変わるところだが、**ビームは全段当たるか1段も当たらないかの2択で、カス当たりが起きない**(実測)。

段が減る現象が無い以上、「1キャストごとに判定・加算」と「全段が同じ上限値を共有」は観測上区別できない。どちらにせよ**ビーム1回 = 加算値1**として扱ってよく、ここまでの数値(上限値99、始動値2)はそのまま生きる。

## 中サンライズの2段の上限値

実験17 は極太×N なのでカウントは `N-1`。

- **スピン部分 = 5**。カウント5(N=6)では当たるが、カウント6(N=7)からは外れる。2ヒットが N=6 で止まるのはこれ。
- **蹴り上げ部分 = 10**。N=7〜11 ではスピンが外れて蹴り上げだけが当たり、カウント11(N=12)で完全に外れる。

**弱サンライズも 10** で一致する。弱サンライズは「その場で蹴り上げ一回転」、中サンライズは「前にスピンしてから蹴り上げ一回転」で、**蹴り上げ部分が共通のモーション**。別々の実験で得た値が揃ったので、互いの裏付けになっている。

## 多段技は段ごとに上限値が違う(SA1)

実験10 の N=98(カウント99)で **SA1 の初段だけが当たり、それ以降が出なかった**。初段は通っているのに続きが出ない以上、段ごとに別の上限値が設定されている。

SA1(Lv1)の挙動:

- **カウント98以下: 全段ヒット**
- **カウント99: 初段のみ(カス当たり)**
- **カウント100: 初段も当たらない** → 上限値(SA1初段) = 99

**SA1 はこれ以上調べる必要がない。** カウントが大きすぎて実戦のコンボでは到底届かないうえ、コンボが続かない〆技なのでルートに影響しない。段ごとの上限値や初段の加算値への分解も不要。

ただしこれは SA1 個別の判断で、多段技一般の記録方針ではない。SA1 はカス当たりするのにビームはしないように、**多段技でも振る舞いは技ごとに違う**ので、その都度観測する。

**段の順番と上限値の大小には関係がない。** SA1 は初段が高く後段が低い(初段だけ当たる)のに対し、中サンライズは逆で後段(蹴り上げ)の方が高い(1段目のスピンだけが外れる)。

## 到達できるカウントの上限は 100

ビームは上限値99なので、カウント99を見る発が最後に通り、その加算で **カウント100** になる。つまりビームで作れる最大カウントは 100(極太なら101回、Lv3ビームなら99回当てた状態)。

### 99 が上限値の最大値ではないか(仮説)

ここまでで上限値が確定した技のうち、**極太ビーム・Lv3ビーム・SA1初段・SA3 の4つがいずれもぴったり 99**。到達できる最大カウントが 100 であることと合わせると、「上限値の最大値が 99 で、カウント100 に達したら何も当たらずコンボが強制終了する」という設計に見える。

ただし 4 件からの推測であって確認されていない。100 以上の上限値を持つ技が出てくれば崩れる。

## 未確定

- J弱2種・J中K はカウント 1 で試していないため、上限値が 0 か 1 以上か不明。
- 加算値(強サンライズ)は 2 以上とだけ判明。**強サンライズの後は極太空中ビーム(ODソーラーフレアLv3)でないとコンボが続かない**ため、上限値が分かっている技(大足など)を当てて挟む手が使えない。空中ビーム側の上限値を先に測る必要がある。
- 上限値 0 と判定した技が、本当に 0 なのかそれ未満なのかは切り分けられていない。極太始動(カウント 0)では 0 以下がすべて「当たる」に潰れるため。6強P始動でカウント 0 未満を作れば分離できる可能性がある。
- 実験2(強サンライズ始動)は浮きの大きさが未確認で、リーチによる「当たらない」を排除できていない。始動値=1 の下限側がこれに依存している。なお実験13で、実験4の「ジャンプ攻撃も全滅」がリーチ由来ではなくカウント由来だったことは裏付けられた。
- 始動値(Lv2ビーム)は 2 以下とだけ判明。連打が使えないので、上限値 2 未満の技(上限値 0 や 1 の技)を当てて詰める。
