# イングリッド コンボカウント考察

観測は [records.md](records.md)、技リストは [moves.md](moves.md)。**このファイルの内容は推定であり、実験が増えれば覆る**。根拠は必ず実験番号で示す。

最終更新: 2026-07-28

## 喰らい方と測定基準

実験3(極太1回 = カウント0)と実験5(極太2回 = カウント1)で、**同じ技**が「当たる(追撃不可)」→「当たらない」に変わった(弱・中・強P)。同一技の比較なので当たり判定やリーチでは説明できない。したがって:

| 喰らい方           | 分かっていること                         |
| ------------------ | ---------------------------------------- |
| **当たらない**     | **カウント超過**(確定)                   |
| **追撃不可ヒット** | カウントは通過している(当たっているため) |
| **追撃可ヒット**   | カウント通過 + 空中やられ継続            |

**上限値の測定は「当たるか当たらないか」で判定する。** 当たった時点でカウントは通過しているので、追撃可否は上限値の判定に使わない。

**未解明: 追撃不可ヒットになる理由。** 「その技が空中やられを継続させない性質を持つ」という解釈はありうるが確認していない。同じ技が別のカウントで追撃可になるかどうかを見れば切り分けられる。

## 極太ビームは目盛りとして直読みできる

極太ビーム(ODLv3)は始動値 0・加算値 1(実験1 の正規化)なので、**極太 N 回で カウント = N-1** をそのまま作れる。実験3 がカウント 0、実験5 がカウント 1。

Lv3ビームを目盛りにする場合は始動値が 2 なので、**N 回で カウント = N+1**。

### 加算値

| 技                                  | 加算値 | 根拠                    |
| ----------------------------------- | ------ | ----------------------- |
| 空中極太ビーム(ODソーラーフレアLv3) | **0**  | 実験22。下記            |
| 極太ビーム                          | 1      | 実験1(正規化により定義) |
| Lv3ビーム                           | 1      | 実験7・実験8            |
| 6強P                                | **1**  | 下記                    |
| 強サンライズ                        | ≥ 2    | 下記                    |

**空中極太ビームの加算値は 0。** 実験22 は地上極太始動(カウント 0)→ 空中極太 → 地上極太 → J中P で、J中P が見るカウントは `加算値(空中極太) + 1`。J中P の上限値は 1 なので `加算値(空中極太) ≤ 0`。実験23 は地上極太をもう1発足したもので、`加算値(空中極太) + 2` が上限値 1 を超えて当たらない → `加算値(空中極太) ≥ 0`。挟んで **ちょうど 0**。

0 という値自体はラッシュ通常技で実在が知られている。**当てても相手のカウントが増えない技**ということになる。

**地上の極太ビームは 1、空中極太ビームは 0。** 同じ ODLv3 でも加算値が違う。始動値は両方 0 で一致していた(実験21)ので、**技の性質は部分的にしか共有されていない**。かつて根拠なく「サンフレアとソーラーフレアは同値」と書いて撤回したが、実測でも同値ではなかった。

**6強Pの加算値は 1 以上。** 実験27 は `6強P > 照射` を繰り返してルミナスアッパー(上限値 0)で締める形。1セットなら、6強P 始動でカウント 0、照射は加算値 0 なので 0 のままで、ルミナスアッパーが当たる。2セットめの 6強P は追撃側に回るので上限値 0 の判定を通った後に `加算値(6強P)` が乗り、照射では動かないまま、ルミナスアッパーがそのカウントを見て外れる → **加算値(6強P) ≥ 1**。

**そして 1 で確定した。** `6強P > 照射` を2セット組んだ時点のカウントを a とすると:

- 実験27 でルミナスアッパー(上限値 0)が外れる → **a ≥ 1**
- 実験28 で 5強K の2段目が当たる → `a ≤ 上限値(5強K 2段目)`。実験29 でこれは **1** と直接測れている

繋ぐと **加算値(6強P) = 1**。

**5強K が2段技だと分かったのは実験28 が初めて。** 実験29 で測り直すと 1段目が上限値 0、2段目が 1 で、過去の記録とも噛み合う。実験3(カウント 0)の「追撃可」は2段とも当たっていた状態、実験5(カウント 1)は2段目だけ、実験4(カウント 2)の「完全に外れる」もそのまま。当時は段数を意識していなかったので気づいていなかった。その後の洗い出しで、多段なのは 5強K と J強K>J強K の2段目だけと分かっているので、他の技は同じ落とし穴を踏んでいない。

**技によって加算値が違うことが実証された。** 実験12 は極太始動(カウント0)から強サンライズを当てており、その後のカウントは `加算値(強サンライズ)` そのもの。ここで J中P(上限値 1)が当たらないので、カウントは 1 を超えている → **加算値(強サンライズ) ≥ 2**。ビームの 1 より大きい。

上限値(J中P) = 1 は実験13で極太始動(浮きが大きくリーチの問題が出ない)により確定しているので、この結論はリーチ由来の誤りに乗っていない。同じ実験で空中ビーム(ソーラーフレア)も当たっているが、ビームの上限値は 99 と大きいので新しい情報は得られない。

## ラッシュ版は上限値が高い

実験36 で `極太ビーム × N → ラッシュ強K` を試すと、カウント 4 で 1hit、カウント 5 で当たらない。**上限値(ラッシュ強K) = 4**。

原技の 5強K は 1段目が 0、2段目が 1 なので、カウント 4 ではどちらの段も当たらない。それがラッシュ版では当たる以上、**ラッシュ版は上限値そのものが高い**。当たったのはおそらく2段目で、その場合 1 → 4 の **+3**。

これは判定が加算前であることとも噛み合う。**ラッシュ通常技の加算値が 0 でも、その技自身が当たるかどうかには効かない**(判定は加算前に行われるため)。それでもラッシュを入れると当たるようになるのは、上限値が上がっているから。

### 差は 3 技とも +3

| 技                     | 原技の上限値 | ラッシュ版 | 差  |
| ---------------------- | ------------ | ---------- | --- |
| 強K(2段目)             | 1            | 4          | +3  |
| 4強P(ルミナスアッパー) | 0            | 3          | +3  |
| 中K                    | 0            | 3          | +3  |

**原技の値が違うのに差が揃っているので、一律 +3 の線が濃い。** ただしまだ 3 技。

ルミナスアッパーは**派生の強Pがラッシュの効果を受けない**。上限値 0 のままなので、ラッシュ 4強P が当たるカウント(3)ではもう超えていて当たらない。

## 2つのビームは始動値だけが違う

実験7(OD始動 → Lv3ビーム連打で100発)と実験8(Lv3始動 → 99発)から:

- 実験7: Lv3ビームの k 発目が見るカウントは `k-1`。100発目が `99 ≤ 上限値`、101発目が `100 > 上限値` → **上限値(Lv3ビーム) = 99**。極太と同じ。
- 実験8: k 発目(k≥2)が見るカウントは `S3 + (k-2)`。99発目が `S3+97 ≤ 99`、100発目が `S3+98 > 99` → **S3 = 2**。

つまり**極太ビームと Lv3ビームは加算値も上限値も同じで、違うのは始動値だけ**(0 と 2)。

なお **「性能段階が1つ下がるごとに始動値 +2」という規則ではない**。それなら性能2段階目は 4 になるはずだが、実験14・実験15 から `始動値(Lv2ビーム) ≤ 2` で、性能3段階目と同じかそれより低い。2段階分の関係を線形に外挿してはいけない。

この「**始動値の差は加算値2ビーム分**」という言い方は単位の取り方に依存しない。仮に加算値が内部で 2 でも `始動値差 = 4 = 2×2` で成り立つので、正規化の選択に巻き込まれない表現になっている。

### Lv2ビームの始動値は連打では測れない

性能2段階目は **0ストックで OD版を撃つ**と出せる(OD(Lv1) = 性能2段階目)。0ストックなら消費するものが無くスタックは 0 のままなので、弱版を挟まない限り連打できる。これで実験1・実験8 と同じ手が使えるはずだった。

しかし実験14 で **Lv2ビーム始動から Lv2ビームが当たらない**。連打が成立しないので、この手順で始動値を測ることはできない。

実験14 で使ったのは 0ストックの OD版(= OD Lv1、性能2段階目)。OD 入力である以上スタックは動かず、2発目も同じ性能2段階目になる。

**そして原因が分からない。** 実験15 で大足の上限値が 2 と確定したので、実験14 から `始動値(Lv2ビーム) ≤ 2`。もし上限値が他のビームと同じ 99 なら `2 ≤ 99` で当たるはずで、当たらない理由がない。

したがって残る可能性は **上限値(Lv2ビーム)だけが極端に低い(2未満)** か、**カウント以外の原因** かの二択。性能3段階目・4段階目がどちらも 99 であることを考えると前者は不自然で、**Lv2ビームの浮きが小さく発生18Fが間に合っていない**線が濃い。

### カウントか発生かを切り分ける実験(未実施)

**プローブに使えるのは SA1 と SA3 だけ。** 上限値 99 と分かっているビームは極太(性能4段階目)と Lv3ビーム(性能3段階目)で、どちらも2ストック必要。Lv2ビームを撃った直後は 0 ストックなので撃てるのは性能1〜2段階目だけで、**上限値が未知のビームしか出せない**。SA1・SA3 はサンスタックを必要としないので使える。

| 技     | 上限値 | 発生 |
| ------ | ------ | ---- |
| SA1    | 99     | 11   |
| ビーム | 不明   | 18   |
| SA3    | 99     | 20   |

**発生Fだけで判断してはいけない。** Lv2ビーム後は発生27Fまでの技が繋がる(実験14)ので、発生18F のビームは 9F も余裕がある計算になる。それでも当たらない。

発生Fは攻撃判定が出るフレームであって相手に届くフレームではない。**ビームは飛び道具なので、判定が出てから相手の位置まで飛翔する時間が上乗せされる**(当てるたびに相手を押し出すなら距離も伸びる)。一方 **SA3 はサーチして相手の位置に弾を出す技**なので飛翔時間がゼロで、20F がそのまま到達フレーム。SA1 も昇竜系で目の前に出るので同様。

つまり「発生27Fまで繋がる」が成り立つのは**相手のいる場所に判定が出る技**であって、ビームは例外。18F のビームが当たらず 20F の SA3 が当たっても矛盾しない。

これは極太で101発繋がったこととも整合する。極太は浮きが大きく滞空が長いので、飛翔時間を払う余裕がある。

SA1 と SA3 は上限値が同じなのでカウントでは区別できず、発生だけが違う。Lv2ビーム始動で両者を試すと:

- **両方当たる**(予測) → ビームが当たらない理由はカウントではない。飛翔時間で説明がつき、カウントモデルは無傷。上限値(Lv2ビーム)は未知のまま残る。
- **SA1 が当たり SA3 が当たらない** → 発生27Fまで繋がるという観測と噛み合わないので、猶予の測り方かモデルのどこかがずれている。
- **両方当たらない** → 上限値 99 が当たらないのにカウント 2 の大足が当たったことになり、カウントでは説明できない。別の機構を疑う。

この手は Lv2ビームだけの話に留まらない。実験2(強サンライズ始動)で残っているリーチ由来の疑いにも、同じく SA1 と SA3 の対で使える。

## 6強P始動は極太始動と同じ

実験6 の始動技は 6強P で、テスト技が見るカウントは `始動値(6強P) + 加算値(空中極太ビーム)`。結果が実験3(カウント 0)と全項目一致し、上限値 0 の技が当たっているので**この和は 0 以下**。実験22 で **加算値(空中極太ビーム) = 0** と分かったので、そのまま `始動値(6強P) ≤ 0`。実験24(地上当てで弱3種が追撃不可ヒット)も独立に同じ上側の制約を与える。

下側は実験25 で切れた。`6強P → 空中極太ビーム(加算値 0)→ 地上極太ビーム(加算値 1)` でカウントを 1 に上げると、上限値 0 の技(弱P・ルミナスアッパー)がどちらも当たらない。負ならここで当たるはずなので **始動値(6強P) = 0**。

### 原点をドライブインパクト始動に繋ぐ(未実施)

README では**原点をドライブインパクト始動に置く**と決めている。全キャラで同じように再現できるからで、他キャラへ数値を輸出するときの足場になる。しかし実際の測定は極太ビーム始動を 0 とした単位系で進んでおり、**両者がまだ繋がっていない**。

繋ぐには `始動値(ドライブインパクト)` をこの単位系で測ればよい。なお実験26 で分かったのは DI の**上限値**(0)であって始動値ではない。

### 壁張り付きの時点で空中コンボは始動している

実験32 で `壁張り付き → 極太ビーム → 弱P` を試すと **弱P が当たらない**(リーチは届いている)。もし極太ビームが始動技ならカウントは 0 になり、上限値 0 の弱P は当たるはずだった。当たらない以上、**極太ビームは追撃側**であり、壁張り付きの時点ですでにカウントが立っている。つまり **ドライブインパクト自身が空中コンボの始動技**。

弱P が見たカウントは `始動値(DI) + 加算値(極太ビーム)` = `始動値(DI) + 1` で、これが 0 を超えている。

### 始動値(DI) = 0。極太始動と同じ点だった

実験33 で `壁張り付き → 極太ビーム × j → 弱サンライズ(上限値 10)` を試すと、**当たる最大の j は 10**。`始動値(DI) + 10 ≤ 10` かつ `始動値(DI) + 11 > 10` なので **始動値(DI) = 0**。

ヒット数も合う。j = 10 のとき 41hits で、これは **ガードさせた DI(0hit)** と極太ビーム 10発 × 4hits、弱サンライズ 1hit の和。

**これで README が宣言していた原点(DI 始動)と、実際に運用してきた原点(極太始動)が同じ点だと分かった。** イングリッドの数値は最初から DI 原点の単位系で書かれていたことになり、平行移動は要らない。他キャラでも DI 始動を 0 に揃えれば、そのまま同じ土俵に乗る。

### 始動値はやられ状況で決まる。ガードかヒットかでは変わらない

同じ手順で DI の当て方を変えて測ると:

| DI の当て方                  | やられ状況 | 当たる最大の j | 始動値 | ヒット数 |
| ---------------------------- | ---------- | -------------- | ------ | -------- |
| ガード(実験33)               | 壁張り付き | 10             | **0**  | 41       |
| ヒット(実験35)               | 壁張り付き | 10             | **0**  | 42       |
| パニッシュカウンター(実験34) | 膝崩れ     | 9              | **1**  | 38       |

ヒット数はいずれも `DI のヒット数 + 極太ビーム(4hits) × 発数 + 弱サンライズ 1hit` で説明がつく(ガードした DI は 0hit)。

**壁張り付きはガードでもヒットでも 0 で変わらない。**変わるのは**やられ状況**の方で、パニッシュカウンターは膝崩れという別の状況を作るから値が違う。「カウンターだから変わる」ではなく「**やられ状況ごとに違う**」と読むのが正しい。

**原点にできるのは片方だけ**なので、**壁張り付きを原点に固定する**。ガード・ヒットどちらからでも到達できるので原点としては堅い。README が「壁張り付き / パニッシュカウンター」と両方を並べていたのは誤りなので直した。

### 強P は当て方で始動値が変わる

同じ 強P でも、当て方によって始動値が違う:

| 当て方                           | やられ状況   | 始動値 | 根拠                                           |
| -------------------------------- | ------------ | ------ | ---------------------------------------------- |
| パニッシュカウンター             | 錐揉みやられ | ≤ 0    | 実験31。弱P(上限値 0)が当たる                  |
| force down(空中の必殺技に当てる) | ダウン       | 1〜10  | 実験40。通常技が当たらず、弱サンライズは当たる |

**同じ技でも状況が違えば別の値になる**。DI で壁張り付きとパニッシュカウンターの始動値が違ったのと同じ話で、始動値はやられ状況で決まると見るのが筋。

**追撃猶予が 9F しかないので詰められない。** 強P の force down は +42F でダウン無敵が標準の 33F、差し引き 9F。発生 9F までの技しか入らず、実際に入るのは弱サンライズだけ。

手持ちのプローブは**速いものが上限値 0 の弱攻撃、次が上限値 10 の弱サンライズ**で、間の 1〜9 を突けるものが無い。だから 1〜10 のまま動かせない。

詰めるなら**弱サンライズを経由する**。弱サンライズの後にビームが入るなら `強P(force down) → 弱サンライズ → 極太ビーム × j → プローブ` でカウントが読める。ただし読めるのは `始動値(強P) + 加算値(弱サンライズ)` の和なので、先に `極太始動 → 弱サンライズ → プローブ` で加算値(弱サンライズ)を測っておく必要がある。

### 0 が始動値の下限ではないか(仮説)

始動値が判明した技は 極太ビーム・空中極太ビーム・6強P がいずれも 0、強サンライズが 1、Lv3ビームが 2 で、**0 を下回るものがまだ 1 つも見つかっていない**。この単位系の原点は極太始動を 0 と置いた任意のものだったが、それが内部の原点と一致している可能性がある。

上限値の最大が 99、到達できる最大カウントが 100 であることと合わせると、**内部のカウントは 0〜100 の範囲**という形になる。

ただし始動値が判明した技はまだ5つ。0 未満の始動技が見つかれば崩れる。

### ターゲットコンボ 中P>中K の派生部分は加算値 0

実験39 で `中P>中K` を始動にすると、その後のカウントは **1**(極太ビーム 9回で弱サンライズが当たり、10回では当たらない)。ヒット数 39 から、中P も中K も当たっている。

中P 単体の始動値も 1 なので、**派生の中K 部分はカウントを増やしていない = 加算値 0**。

なお**ターゲットコンボの派生は単体の技とは別の技**なので、単体の 中K の値(上限値 0)を当てはめてはいけない。派生には派生の値がある。

### 通常技の始動値は今のところ全部 1

測れた通常技は **弱P・中P・中K・J中P の4つで、いずれも 1**。技の強度もボタンも違うのに揃っているので、**通常技は一律 1** の可能性がある。ビーム系(0 や 2)や 6強P(0)とは別の値なので、技の種別ごとにまとまっているように見える。

### 始動値の測り方

始動技の後に極太ビームを j 回はさんでからプローブ技を当てると、プローブが見るカウントは `始動値 + j`。したがって:

```
始動値 = プローブの上限値 − 当たる最大の j
```

**上限値 10 の技(弱サンライズ・上バニッシュ)をプローブにすれば 0〜10 を一度の探索で読める**。刻んでプローブを取り替えるより速い。実験30 の弱P はこの手で 1 と出た。

始動させるには相手が空中にいる必要がある。実験31 では**ラシードの空中を進む技を的にする**方法を使っており、複数の技を同じ条件で並べて測れる。ただし**下段部分は当たらない**ので測れる技が限られる。弱P はこの方法でも 1 になり、実験30(極太ビーム + 弱サンライズ)と一致した。設定が違っても同じ値が出たので、手法そのものの裏付けにもなっている。

**極太ビームを挟むのは値をずらすためだけ**なので、ビームが間に合わない始動技でも**プローブを直接当てれば `始動値 ≤ プローブの上限値` は読める**。上限値 0(弱P)→ 1(5強K)→ 2(大足)の順に当てていけば、通常技の値が今のところ全部 1 である以上たいていそこで決まる。

実験31 で測れなかった技には、それぞれ別の入り口が要る:

- **強P**: 後にビームが間に合わない。上記のとおりプローブを直接当てればよい。
- **強K**: 叩きつけ系で SA キャンセルしかできず、プローブが SA に限られる。SA1 も SA3 も上限値 99 なので何も切れない。**SA2 の上限値がまだ未測定**なので、これが低ければプローブとして使える。
- **6中P**: 攻撃判定が下の方にあり空中のラシードに届かない。**もっと低い位置に相手がいる状況**が要る。ドライブインパクトの膝崩れ(空中判定部分)は追撃可のダウンになるうえ高さも低いので候補。

**4中K は追撃が繋がらないため測定できない。** ただし `4中K > 強P(ヘイローステップ) → 中サンライズ` はコンボとして入るので、`始動値(4中K) + 加算値(4中K) ≤ 上限値(中サンライズの当たった段)` という制約は取れる。中サンライズのどちらの段が当たったかを見れば、上限値 5(スピン)か 10(蹴り上げ)かで境界が決まる。

### プローブ技でカウントを読む(連打より安い)

地上極太ビームは加算値 1 なので、**数発はさむだけでカウントを +1 ずつ動かせる**。上限値が分かっている技を当てて通るかどうかを見れば、100発数えなくてもカウントが読める。

| プローブ             | 上限値 |
| -------------------- | ------ |
| 弱P など             | 0      |
| 5強K / J中P          | 1      |
| 大足                 | 2      |
| 中サンライズ・スピン | 5      |
| 弱サンライズ         | 10     |

**負のカウントを読むときが特に安い。** カウント C の状態から地上極太を j 発足すと `C + j` になるので、上限値 0 のプローブが当たる最大の j を探せば `C = −j`。C が −3 なら4回試すだけで済む。正のカウントならプローブの方を上げていけばよい。

実験21 はこの手で 2 回の試行で決まった。空中極太始動から地上極太を 1 発はさむとカウントは `S+1` で、J中P(上限値 1)が当たるので `S ≤ 0`。2 発はさむと `S+2` で当たらないので `S ≥ 0`。よって **始動値(空中極太ビーム) = 0** で、地上の極太ビームと一致する。

サンフレアとソーラーフレアの関係に初めて実測が入ったことになる(かつて根拠なく「同値」と書いて撤回した経緯がある)。ただし一致が確認できたのは **ODLv3 同士の始動値だけ**で、加算値・上限値や他の Lv については未確認。

### 地上極太ビームの連打を物差しにして数値化する

実験18・実験19 から、**6強P 始動でも空中極太ビーム始動でも、その後に地上の極太ビームが繋がる**ことが分かった。地上極太ビームは加算値 1・上限値 99 なので、**その後に何本入るかを数えれば、数え始めた時点のカウントがそのまま出る**。

入る本数を K とすると、`カウント = 100 − K`(実験1 で極太始動から100発入ったのと同じ勘定)。

これを3通り走らせると未知数が全部解ける:

| #   | コンボ列                                                 | 数え始めた時点のカウント        | 状況             |
| --- | -------------------------------------------------------- | ------------------------------- | ---------------- |
| 1   | 空中極太ビーム始動 → 地上極太ビーム連打                  | 始動値(空中極太)                | 実験21 で解決(0) |
| 3   | 地上極太ビーム始動 → 空中極太ビーム → 地上極太ビーム連打 | 加算値(空中極太)                | 実験22 で解決(0) |
| 2   | 6強P → 空中極太ビーム → 地上極太ビーム連打               | 始動値(6強P) + 加算値(空中極太) | 未実施           |

加算値(空中極太) = 0 が出たので、**2 はそのまま始動値(6強P) を与える**。実験6 の `始動値(6強P) + 加算値(空中極太) ≤ 0` と合わせると `始動値(6強P) ≤ 0`。

いずれも連打せずプローブ技で解けている。連打が要るのは値がプローブの範囲(0〜10)を外れると分かったときだけ。

**K が 100 を超えたら和が負**、つまりカウントが極太始動の原点より下に行けることが確定する。実験6 では「0 以下」までしか言えていなかったので、そこが数値になる。負のカウントが実在するなら、これまで「上限値 0」に潰れて見えていた技の中に負の上限値を持つものがある可能性が出てきて、切り分けの入り口になる。

## ビームは多段技だが1キャスト単位で扱ってよい

**ODLv3ビームは4ヒット、Lv3ビームは3ヒット**の多段技。加算がヒットごとなら上限値は極太で396〜400、Lv3ビームで297〜300あたりに変わるところだが、**ビームは全段当たるか1段も当たらないかの2択で、カス当たりが起きない**(実測)。

段が減る現象が無い以上、「1キャストごとに判定・加算」と「全段が同じ上限値を共有」は観測上区別できない。どちらにせよ**ビーム1回 = 加算値1**として扱ってよく、ここまでの数値(上限値99、始動値2)はそのまま生きる。

## 中サンライズの2段の上限値

実験17 は極太×N なのでカウントは `N-1`。

- **スピン部分 = 5**。カウント5(N=6)では当たるが、カウント6(N=7)からは外れる。2ヒットが N=6 で止まるのはこれ。
- **蹴り上げ部分 = 10**。N=7〜11 ではスピンが外れて蹴り上げだけが当たり、カウント11(N=12)で完全に外れる。

**弱サンライズも 10** で一致する。弱サンライズは「その場で蹴り上げ一回転」、中サンライズは「前にスピンしてから蹴り上げ一回転」で、**蹴り上げ部分が共通のモーション**。別々の実験で得た値が揃ったので、互いの裏付けになっている。

## 多段技は段ごとに上限値が違う(SA1)

実験10 の N=98(カウント99)で **SA1 の初段だけが当たり、それ以降が出なかった**。初段は通っているのに続きが出ない以上、段ごとに別の上限値が設定されている。

SA1(Lv1)の挙動:

- **カウント98以下: 全段ヒット**
- **カウント99: 初段のみ(カス当たり)**
- **カウント100: 初段も当たらない** → 上限値(SA1初段) = 99

**SA1 はこれ以上調べる必要がない。** カウントが大きすぎて実戦のコンボでは到底届かないうえ、コンボが続かない〆技なのでルートに影響しない。段ごとの上限値や初段の加算値への分解も不要。

ただしこれは SA1 個別の判断で、多段技一般の記録方針ではない。SA1 はカス当たりするのにビームはしないように、**多段技でも振る舞いは技ごとに違う**ので、その都度観測する。

**段の順番と上限値の大小には関係がない。** SA1 は初段が高く後段が低い(初段だけ当たる)のに対し、中サンライズは逆で後段(蹴り上げ)の方が高い(1段目のスピンだけが外れる)。

## 到達できるカウントの上限は 100

ビームは上限値99なので、カウント99を見る発が最後に通り、その加算で **カウント100** になる。つまりビームで作れる最大カウントは 100(極太なら101回、Lv3ビームなら99回当てた状態)。

### 99 が上限値の最大値ではないか(仮説)

ここまでで上限値が確定した技のうち、**極太ビーム・Lv3ビーム・SA1初段・SA3 の4つがいずれもぴったり 99**。到達できる最大カウントが 100 であることと合わせると、「上限値の最大値が 99 で、カウント100 に達したら何も当たらずコンボが強制終了する」という設計に見える。

ただし 4 件からの推測であって確認されていない。100 以上の上限値を持つ技が出てくれば崩れる。
