# イングリッド コンボカウント考察

観測は [records.md](records.md)、技リストは [moves.md](moves.md)。**このファイルの内容は推定であり、実験が増えれば覆る**。根拠は必ず実験番号で示す。

最終更新: 2026-07-28

## 喰らい方3種の意味

実験3(極太1回 = カウント0)と実験5(極太2回 = カウント1)で、**同じ技**が「当たる(追撃不可)」→「当たらない」に変わった(弱・中・強P)。同一技の比較なので当たり判定やリーチでは説明できない。したがって:

| 喰らい方           | 意味                                                                   |
| ------------------ | ---------------------------------------------------------------------- |
| **当たらない**     | **カウント超過**                                                       |
| **追撃不可ヒット** | カウントは通過している。その技が空中やられを継続させないだけ(技の性質) |
| **追撃可ヒット**   | カウント通過 + 空中やられ継続                                          |

**上限値の測定は「当たるか当たらないか」で判定する。追撃可否は上限値と無関係。**

## 極太ビームは目盛りとして直読みできる

極太ビーム(ODLv3)は始動値 0・加算値 1(実験1 の正規化)なので、**極太 N 回で カウント = N-1** をそのまま作れる。実験3 がカウント 0、実験5 がカウント 1。

### 2つのビームは始動値だけが違う

実験7(OD始動 → Lv3ビーム連打で100発)と実験8(Lv3始動 → 99発)から:

- 実験7: Lv3ビームの k 発目が見るカウントは `k-1`。100発目が `99 ≤ 上限値`、101発目が `100 > 上限値` → **上限値(Lv3ビーム) = 99**。極太と同じ。
- 実験8: k 発目(k≥2)が見るカウントは `S3 + (k-2)`。99発目が `S3+97 ≤ 99`、100発目が `S3+98 > 99` → **S3 = 2**。

つまり**極太ビームと Lv3ビームは加算値も上限値も同じで、違うのは始動値だけ**(0 と 2)。性能段階が1つ下がることが始動値 +2 として現れている。

この「**始動値の差は加算値2ビーム分**」という言い方は単位の取り方に依存しない。仮に加算値が内部で 2 でも `始動値差 = 4 = 2×2` で成り立つので、正規化の選択に巻き込まれない表現になっている。

**6強P始動のカウントは極太始動と同じかそれより低い。** 実験6 の始動技は 6強P で、テスト技が見るカウントは `始動値(6強P) + 加算値(ODソーラーフレアLv3)`。結果が実験3(カウント 0)と全項目一致し、上限値 0 の技が当たっているので**この和は 0 以下**。ソーラーフレアの加算値がサンフレアと同じ 1 なら **始動値(6強P) ≤ −1** となり、極太始動より低いカウントを作れる始動技ということになる。

## 多段技は段ごとに上限値が違う(実測で確認)

実験10 の N=98(カウント99)で **SA1 の初段だけが当たり、それ以降が出なかった**。初段は通っているのに続きが出ない以上、段ごとに別の上限値が設定されている。

SA1(Lv1)の挙動:

- **カウント98以下: 全段ヒット**
- **カウント99: 初段のみ(カス当たり)**

**SA1 はこれ以上調べる必要がない。** カウントが大きすぎて実戦のコンボでは到底届かないうえ、コンボが続かない〆技なのでルートに影響しない。段ごとの上限値や初段の加算値への分解も不要。

ただしこれは SA1 個別の判断で、多段技一般の記録方針ではない。他の多段技が同じ振る舞いをする保証はないので、その都度観測する。

## 到達できるカウントの上限は 100

ビームは上限値99なので、カウント99を見る発が最後に通り、その加算で **カウント100** になる。つまりビームで作れる最大カウントは 100 で、そこまでは検証技を試せる。極太なら 101 回、Lv3ビームなら 99 回当てた状態。SA1初段のように 99 で当たってしまう技は、この 100 まで押し上げて試せば上限値が確定する可能性がある。

## そのほか

- **2強K > 5強K**。実験4で大足だけ当たった。
- 性能が1段階下がる(極太 → Lv3ビーム)と始動値が 0 から 2 に上がる。上限値と加算値は変わらない。
- イングリッドの通常技・特殊技は**大半が上限値 0**。カウントが 1 になった時点で生き残るのは 5強K・2強K・J中P・J強P だけ。

- ~~サンフレアとソーラーフレアは同じ値を持つ~~ — 実験3と実験6が全項目一致したことを根拠にしていたが、両者は始動技が違う(極太始動 vs 6強P始動)ので比較になっていない。撤回(2026-07-28)。

## 未確定

- J弱2種・J中K はカウント 1 で試していないため、上限値が 0 か 1 以上か不明。
- 2強K(大足)の上限値は 2 以上とだけ判明。**ただし優先度は低い** — 大足の後はコンボが絶対に続かないのでコンボルートに影響せず、実用上は無限扱いでよい。深いカウントまで届くプローブ技としての用途もビーム(上限値99、当てやすく浮きも大きい)が上位互換。加えて大足自体が当てにくく、入力ミスとカウント超過を取り違えやすい。
- 実験2(強サンライズ)は浮きの大きさが未確認で、リーチによる「当たらない」を排除できていない。
- 上限値 0 と判定した技が、本当に 0 なのかそれ未満なのかは切り分けられていない。極太始動(カウント 0)では 0 以下がすべて「当たる」に潰れるため。6強P始動でカウント 0 未満を作れば分離できる可能性がある。
