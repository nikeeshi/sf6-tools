# イングリッド コンボカウント考察

観測は [records.md](records.md)、技リストは [moves.md](moves.md)。**このファイルの内容は推定であり、実験が増えれば覆る**。根拠は必ず実験番号で示す。

最終更新: 2026-07-28

## 喰らい方3種の意味

実験3(極太1回 = カウント0)と実験5(極太2回 = カウント1)で、**同じ技**が「当たる(追撃不可)」→「当たらない」に変わった(弱・中・強P)。同一技の比較なので当たり判定やリーチでは説明できない。したがって:

| 喰らい方           | 意味                                                                   |
| ------------------ | ---------------------------------------------------------------------- |
| **当たらない**     | **カウント超過**                                                       |
| **追撃不可ヒット** | カウントは通過している。その技が空中やられを継続させないだけ(技の性質) |
| **追撃可ヒット**   | カウント通過 + 空中やられ継続                                          |

**上限値の測定は「当たるか当たらないか」で判定する。追撃可否は上限値と無関係。**

## 極太ビームは目盛りとして直読みできる

極太ビーム(ODLv3)は始動値 0・加算値 1(実験1 の正規化)なので、**極太 N 回で カウント = N-1** をそのまま作れる。実験3 がカウント 0、実験5 がカウント 1。

## 上限値

| 技                                    | 上限値         | 根拠                                          |
| ------------------------------------- | -------------- | --------------------------------------------- |
| 弱 4種(5LP/5LK/2LP/2LK)               | 0              | 実験3で当たり、実験5で当たらない              |
| 中 4種(5MP/5MK/2MP/2MK)               | 0              | 同上                                          |
| 強P 2種(5HP/2HP)                      | 0              | 同上                                          |
| 6中P / 6強P / 4中K / ルミナス(4HP>HP) | 0              | 同上(実験5「その他の特殊技」)                 |
| J強K                                  | 0              | 実験3で当たり、実験5で当たらない              |
| 5強K                                  | 1 以上 S3 未満 | 実験5で当たる。実験4(カウント S3)で当たらない |
| 2強K(大足)                            | S3 以上(≥ 2)   | 実験5で当たる。実験4でも当たる                |
| J中P                                  | 1 以上 S3 未満 | 実験5で当たる。実験4で当たらない              |
| J強P                                  | ≥ 1            | 実験5で当たる(追撃不可だがヒットはする)       |
| ODサンフレアLv3                       | 99             | 実験1(始動値 0・加算値 1 の正規化の下)        |

`S3` = Lv3ビーム(性能3段階目)の始動値。下記より 2 以上。

## 始動値

| 始動技                 | 始動値     | 根拠                                                                                                                          |
| ---------------------- | ---------- | ----------------------------------------------------------------------------------------------------------------------------- |
| 極太ビーム(ODLv3)      | 0          | 定義上の原点(実験1 の正規化)                                                                                                  |
| Lv3ビーム(性能3段階目) | ≥ 2 (= S3) | 実験4で 5強K(上限値 ≥ 1)が当たらない → カウントは 2 以上。Lv3ビームも浮きは大きいので、この「当たらない」はリーチ由来ではない |
| 強サンライズ           | ≥ 1        | 実験2で J強K(上限値 0)が当たらない。ただし浮きの大きさ未確認のためリーチ由来を排除できていない                                |
| 6強P                   | ≤ 0        | 下記                                                                                                                          |

**6強P始動のカウントは極太始動と同じかそれより低い。** 実験6 の始動技は 6強P で、テスト技が見るカウントは `始動値(6強P) + 加算値(ODソーラーフレアLv3)`。結果が実験3(カウント 0)と全項目一致し、上限値 0 の技が当たっているので**この和は 0 以下**。ソーラーフレアの加算値がサンフレアと同じ 1 なら **始動値(6強P) ≤ −1** となり、極太始動より低いカウントを作れる始動技ということになる。

## そのほか

- **2強K > 5強K**。実験4で大足だけ当たった。
- 性能が1段階下がる(極太 → Lv3ビーム)と始動値が 0 から 2 以上に跳ねる。
- イングリッドの通常技・特殊技は**大半が上限値 0**。カウントが 1 になった時点で生き残るのは 5強K・2強K・J中P・J強P だけ。

## 撤回した仮説

- ~~サンフレアとソーラーフレアは同じ値を持つ~~ — 実験3と実験6が全項目一致したことを根拠にしていたが、両者は始動技が違う(極太始動 vs 6強P始動)ので比較になっていない。撤回(2026-07-28)。

## 未確定

- `S3` の正確な値(2 以上とだけ判明)。Lv3ビームを複数回当てれば `S3 + 加算値` が作れるので詰められる。
- J弱2種・J中K はカウント 1 で試していないため、上限値が 0 か 1 以上か不明。
- 実験2(強サンライズ)は浮きの大きさが未確認で、リーチによる「当たらない」を排除できていない。
- 上限値 0 と判定した技が、本当に 0 なのかそれ未満なのかは切り分けられていない。極太始動(カウント 0)では 0 以下がすべて「当たる」に潰れるため。6強P始動でカウント 0 未満を作れば分離できる可能性がある。
