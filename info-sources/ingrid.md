## 8/3(Year4)の調整差分

公式のバトル変更リスト([common.md](common.md))から確定値で取得。**強化のみ、弱体化なし。**

| 技                   | 内容                                                           |
| -------------------- | -------------------------------------------------------------- |
| 立ち弱K              | ヒット時の硬直差 **+2F ⇒ +3F**                                 |
| 立ち中K              | ヒット時の硬直差 **+3F ⇒ +4F**                                 |
| 【強】サンシュート   | 空中ヒット時の横吹き飛び減少・吹き飛び時間増加・ダウン時間 -1F |
| 【OD強】サンシュート | 空中ヒット時の横吹き飛び減少                                   |
| 【OD】サンシュート   | 初段のコンボカウント加算増・2段目の加算減                      |
| 【弱】サンライズ     | 動作 **8F〜10F に投げ無敵**を付与                              |
| 【CA】コズミックレイ | 不具合修正(ロック演出に移行しないことがある)                   |

公式の意図は「サンシュートを空中の相手に引っかけた際の追撃を整え、**強サンライズ(↓↘→+強K)をコンボに
組み込みやすくする**」。立ち中Kののけぞり増加により、**パニッシュカウンター時・ドライブラッシュから
強サンライズが連続ヒットするようになった**。

**古い情報を読むときの読み替え:**

- **コンボは古い情報がそのまま使える。** 増えた方向の変更なので、8/3 以前のレシピが通らなくなることはない。
  ただし**強サンライズを組み込む新ルートは 8/3 以前の記事には載っていない**
- **起き攻め・固めのフレーム表記は2箇所だけ読み替える** — 立ち弱K と立ち中K のヒット後が各 +1F。
  かくぶろ・ドスの連係表はこの2技が絡む部分だけ +1F 有利に振れている
- **モダン操作の変更は入っていない。** 8/3 は一部キャラのモダンで技の割り当てが変わったが、
  イングリッドは対象外

### かくぶろのセットプレイ記事(採用・2周)

**全サイト中いちばん狙いに近い。** 採用理由は「有利フレームが付いているから」ではなく、
**周回数が多いから**。

- 始動ごとに有利Fを書き、そこから前ステ/シミー/持続重ね/様子見に枝を張る分岐ツリー

- **その対応への返しまで書いてある。** 例:「中サンライズ(+38)：即弱サンフレアを出すと、その場受け身
  された場合 -10 を背負った所に強Pなどを確定させられる。**基本的には非推奨**」→ 攻め・受け・だから別の択、
  と2周している
- 執筆者は**格ゲーブロガー拓**。2026-05-25 公開、**2026-08-02 更新**。「新しい連係を発見＆開発次第、
  更新していきます」と明言。**継続型**
