## 引き継ぎ: ネットワークは開通済み

**2026-08-09 にポリシーが変更され、外部サイトを読めるようになった。** note・YouTube・X・Reddit・
攻略ブログ・公式サイトすべて到達する。前セッションで書かれていた「全部 403」の状態は解消済み。

**注意点2つ。**

- **`streetfighter.com` は素の curl だと 403 を返す。** ブラウザの User-Agent を付ければ 200。
  ポリシーではなくサイト側の UA 判定なので、403 を見てもポリシーのせいだと判断しない
- **note は API が使える。** 記事一覧 `note.com/api/v2/creators/<urlname>/contents?kind=note&page=N`、
  本文 `note.com/api/v3/notes/<key>`、ハッシュタグ `note.com/api/v3/hashtags/<tag>/notes?order=new&page=N`。
  検索 API(`/api/v3/searches`)は 403 になる

## 前提(新しいセッションが知らないこと)

- **目的は攻略情報を取ること。** move-db・combo-count はゲーム仕様を実測から推定するボトムアップの作業だが、
  info-sources は**その逆**。「この技が強い」「この連携が強い」といった、**自分では測っても出てこない情報**を
  人から取るためにある。フレームデータや仕様データを集める作業ではない
- **今やっているのは情報を取ることではなく、情報源を探すこと。** 順番を飛ばさない
- **対象キャラは [combo-tree](../combo-tree/README.md) に合わせる**(Mリリー・Cエレナ・Mイングリッド)。
  **操作タイプまで含めて対象**なので、モダン/クラシックの別は情報源の選別に効く
- **日本語・英語の両方が対象。** 日本のプレイヤーは強いが海外勢も活躍しているので切り捨てない
- **`wiki.supercombo.gg` は除外済み**(理由は README の除外リスト)
