## 引き継ぎ: ネットワークポリシー

**2026-08-09 時点の状況。** この作業環境は egress が GitHub とパッケージレジストリのみ許可になっており、
攻略サイト・note・YouTube・X・Reddit・公式サイト(`streetfighter.com`)はすべて CONNECT に 403 が返る。
そのため **info-sources の全エントリが「未読」で止まっている** — サイトの存在と扱う内容までは検索で分かるが、
中身を読んでいないので質の判定ができていない。

ポリシーは環境の設定項目なので、**変更するには新しい環境(セッション)を立てる必要がある**。

### 最初にやること: 開通しているか確認する

```bash
curl -sS -o /dev/null -w "%{http_code}\n" --max-time 15 -x "$HTTPS_PROXY" --cacert /root/.ccr/ca-bundle.crt https://note.com/
```

200番台か 301/302 が返れば開通。403 なら塞がったまま。`curl -sS "$HTTPS_PROXY/__agentproxy/status"` で
直近の拒否理由も見られる。

**egress ポリシーは組織の設定なので、塞がっていた場合に迂回を試みない。** 塞がっているという事実を報告して、
検索ベースの作業に切り替える。

### 開通していた場合(優先順)

1. **`note.com/madarakakikaki`(madaraomi)の最新 Act の記事** → イングリッドの MR 上位プレイヤーを引く。
   **これが本命。** イングリッドは大会に出てこないので、ここが唯一まともな逆引き経路
2. **`sf6-ingrid.com`** → 運営者・更新頻度・専任かどうか。独立ドメインのキャラ専用サイトなので期待値が高い
3. **かくぶろのセットプレイ記事・dos236236 の note** → 中身の深さを判定し、確認状態を「既読」→「採用/除外」に更新
4. 各サイトが**当たり判定の画像や数値を載せていないか**を確認する。載せていたら README の除外基準に従って
   除外リストに追加する(判断は勝手にせず、理由を添えて報告する)

### 塞がったままの場合

検索ベースで索引を広げる作業に切り替える(下の残タスクの「横断」側が進めやすい)。
**中身の評価はできないので、拾ったものは「未読」のまま積む。** 読んでいないものを読んだように書かない。

## 前提(新しいセッションが知らないこと)

- **目的は攻略情報を取ること。** move-db・combo-count はゲーム仕様を実測から推定するボトムアップの作業だが、
  info-sources は**その逆**。「この技が強い」「この連携が強い」といった、**自分では測っても出てこない情報**を
  人から取るためにある。フレームデータや仕様データを集める作業ではない
- **今やっているのは情報を取ることではなく、情報源を探すこと。** 順番を飛ばさない
- **対象キャラは [combo-tree](../combo-tree/README.md) に合わせる**(Mリリー・Cエレナ・Mイングリッド)。
  イングリッドから着手した
- **日本語・英語の両方が対象。** 日本のプレイヤーは強いが海外勢も活躍しているので切り捨てない
- **`wiki.supercombo.gg` は除外済み**(理由は README の除外リスト)
