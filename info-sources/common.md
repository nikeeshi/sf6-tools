### Liquipedia(採用) — 大会経路は実際に使える

**以前ここには「イングリッドは EWC 2026 Top8 に0人だから大会経路は使えない」と書いてあったが、
これは誤りだった。** 1大会の Top8 だけを見て経路そのものを否定していたうえ、**大会を一度も漁っていなかった**。
実際に Liquipedia を漁ったら、イングリッド使いは世界各地に複数いて優勝者もいた([ingrid.md](ingrid.md))。

**Top8 の顔ぶれは母数ではない。** そもそも Top8 は8人しかいないので、母数が小さいキャラが入らないのは当然。
**必ず実際に漁ってから判断する。**

**API の使い方**(そのまま再現できるように残す):

- エンドポイントは `https://liquipedia.net/fighters/api.php`(MediaWiki API)
- **gzip 必須。** 付けないと 406 が返る → `curl --compressed -H "Accept-Encoding: gzip"`
- User-Agent に連絡先を入れる(利用規約)
- 検索: `action=query&list=search&srsearch=insource%3A%22Ingrid%22&srlimit=20&format=json`
- 本文: `action=query&prop=revisions&rvprop=content&rvslots=main&titles=A|B|C&format=json`

**wikitext から拾えるもの3種:**

1. 参加者・順位表 — `{{SoloOpponent|選手名|flag=jp|chars=ingrid|team=...}}`。**選手名と使用キャラが対**
2. ブラケット — `{{Match|opponent1={{SoloOpponent|名前}}...|map1={{Map|o1p1={{Chars|ingrid}}|o2p1={{Chars|ken}}}}`。
   **試合単位でどちらがどのキャラを使ったか**まで分かる。ここまで取れると「大会でそのキャラを何試合投げたか」
   が数えられるので、**片手間で触っただけの人と本当に使っている人を分けられる**
3. **選手ページの `Infobox player`** — `|twitter=` `|twitch=` `|youtube=` `|startgg=` `|localid=`(日本語表記)
   `|team=`。**大会で拾った選手の発信先がそのまま取れる**

**3 が効く。** 「名簿は引けるが発信先に繋がらない」という詰まりが、**大会経路については解消する**
(ランクマ名簿の CFN 名からの逆引きは依然として未解決)。選手名をそのままページ名として
`titles=Sako|Punk|Problem X&redirects=1` で引ける。

### 落とし穴2つ(どちらも実際にやらかした)

**1. 年で絞らないとゲームが混ざる。** キャラ名で検索すると全期間・全タイトルの大会が引っかかる。
実例として、**エレナはウルトラストリートファイター4にも登場する**ので、年を見ずに集計したら
2014〜2015年のウル4勢(Sako・Tokido・Xian・Justin Wong など)が大量に混入した。
**大会ページのタイトルに年が入っている**(`Capcom Pro Tour/2026/...`)ので、そこで絞る。

**2. 年を見ないと「昔使っていた人」が現役に見える。** ぷげらは 2023〜2024年にリリーを挙げていたが
2024年以降は使っていない。**年ごとの集合として持ち、2025年以降に出てくるかどうかで現役判定する。**

**もう一つの注意。** 「Ingrid」という名前のプレイヤーが別ゲーム(EVO 2023 Japan の鉄拳・VF)に存在する。
**キャラ名と人名の衝突**があるので、SF6 のページに限定してから拾う。

**全31キャラを一度に埋めるなら、大会ページ側から引くほうが桁で速い。** キャラ名で検索すると
1キャラあたり数十ページを引くことになるが、**主要大会14ページを取るだけで全キャラの選手が埋まる**。

Blink Respawn 2026・Combo Breaker 2026・BAM16・VSFighting 2026・Battle of BC 8・Only The Best 8・

**キャラ名の表記ゆれを吸収する必要がある。** `bison`/`m. bison`/`vega` が同じ、`akuma`/`gouki` が同じ、
`chun`/`chun-li`、`honda`/`e. honda`、`dj`/`dee jay`、`aki`/`a.k.i.`、`viper`/`c. viper` など。

### チームページから非選手スタッフを引く(経路5)

**`{{Person|<id>|flag=..|role=<役割>|team=..}}`** の `role` が肝。Player 以外を拾うと、
**アナリスト・ストリーマー・ユース・コーチ**が出てくる(README の経路5)。

`leavedate=` があるものは退団済みなので除外する。

  **combo-tree の対象は Mリリー・Mイングリッドなので、モダン側の変更は毎回確認する必要がある**
  (8/3 時点ではリリーが対象、イングリッドは対象外)

**Buckler's の統計2つは公式が出す唯一の勝率データ**なので価値が高い。対戦ダイアグラムはキャラ対策の
優先順位を決めるのに直接使える(どの相手に負けているかが分かる)。ただし公式サイトは SPA で、
move-db のフレーム表と同じくブラウザから手動で取る必要がある可能性が高い。

### 公式サイトへのアクセス

**`streetfighter.com` は素の curl だと 403 を返すが、ブラウザの User-Agent を付けると 200 が返る。**
ネットワークポリシーの問題ではなく、サイト側の UA 判定。前セッションで「公式サイトが 403」と
記録していたのはこれが原因の可能性がある。

## X(Twitter)のキャラ別ハッシュタグ

**キャラごとにハッシュタグを付けて投稿する文化がある。** 規約は `#SF6_<キャラ英名>` で、
`#SF6_Ingrid`・`#sf6_elena` のように使われる(大文字小文字の揺れあり)。

**使い方は「投稿を数える」ではなく「人を見つける」。** タグを時系列で眺めて、**よく攻略情報を上げている人**を
拾う。これが**探索型を見つける現実的な入口**(README の経路4)。MR 名簿にも大会結果にも出てこない人が、
ここには出てくる。

### X を直接叩かずに X の投稿を見る

**X は利用規約でスクレイピングを禁止している。** API は有料でないと使えず、Grok に調べさせる手も
課金が要る。**`x.com/<handle>` を curl で取る方法は使わない。**

**このリポジトリでは 2026-08-09 に一度それをやってしまった。** 規約を確認する前に
`x.com/sakonoko` などのプロフィールを直接取得している。**規約違反にあたるので以降はやらない。**
そこで得た情報(sako の配信休止、Hibiki の自己紹介など)は記録として残してあるが、
**同じ取り方を繰り返さない。**

**代わりに Yahoo リアルタイム検索を使う。** X の投稿を検索できる**通常の検索サービス**で、
普通に開けて機械的にも読める。

- `https://search.yahoo.co.jp/realtime/search?p=<クエリをURLエンコード>`
- HTML 内の `__NEXT_DATA__` の `props.pageProps.pageData.timeline.entry` が投稿の配列
- 使えるフィールド: `screenName`(@ハンドル)・`name`(表示名)・`createdAt`(UNIX秒)・
  `displayText`(本文)・`likesCount`・`rtCount`・`url`
- **1クエリあたり最大40件**しか返らない。総数ではなく直近40件

**これで経路3(ハッシュタグから人を見つける)が全キャラで実行できるようになった。**
結果は [characters.md](characters.md) の「X のハッシュタグの投稿者」。

**頻度で並べると全キャラ投稿アカウントが1位になる。** `@shoryuken00000` は19キャラ・186件に出てくる。
**投稿数の多さは有用さの指標ではない**ので、**何キャラに出ているかで名寄せして分離する**
(madaraomi の名簿でユーザコードで名寄せしたのと同じ手)。

### そのほか、この環境から見えるもの

**2026-08-09 に確認。**

| 対象                     | 見えるもの                                                                         |
| ------------------------ | ---------------------------------------------------------------------------------- |
| **YouTube のチャンネル** | **RSS で直近15本のタイトルと公開日**が取れる。何を出している人かはこれで判定できる |
| YouTube の動画本体       | **不可**(映像も音声も字幕も取れない)                                               |
| Twitch                   | ページは開くが配信内容は当然読めない                                               |

**YouTube の RSS の取り方:**

1. チャンネルページ(`youtube.com/@<handle>` や `youtube.com/user/<name>`)を取得
2. HTML 内の `"externalId":"UC..."` からチャンネル ID を抜く
3. `https://www.youtube.com/feeds/videos.xml?channel_id=UC...` を取る

**動画の中身は判定できないが、タイトルと日付の並びだけで「今も出しているか」「何を扱っているか」は
かなり分かる。** 実例として ElChakotay のチャンネルは、タイトルだけで対象3キャラを継続的に扱っていること
と、8/3 パッチ直後に対応動画を出していることが確定できた。

note にもハッシュタグ索引がある: `note.com/nikotarosun/m/m2e64b4dadc37/hashtag`(にこ太郎)。
note 側は `note.com/api/v3/hashtags/<tag>/notes?order=new&page=N` で機械的に引ける。
