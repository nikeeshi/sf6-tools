# コンボカウント

コンボの段数を数える内部値。パッチノートにしか記述が無く、フレーム表にもゲーム内にも出てこない。原文では用語マーカー付き(`<div data-word='combo_count'>`)で書かれることが多い。

パラメータは3つ確認できている。

| パラメータ | 意味として読めること                         | 出典                                                                                                                                                                                                                                               |
| ---------- | -------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 始動値     | その技でコンボを始めたときの初期値           | [2024.05](../patch-notes/battle-change/202405.md#L314) MARISA「ファルクスクラッシュ」(増加)、[2024.05](../patch-notes/battle-change/202405.md#L186) JAMIE「点辰」                                                                                  |
| 加算値     | その技が当たるたびに足される量               | [2024.05](../patch-notes/battle-change/202405.md#L161) JAMIE「しゃがみ強K」(初段のみ減少)、[2024.05](../patch-notes/battle-change/202405.md#L314) MARISA「ファルクスクラッシュ」(減少)                                                             |
| 上限値     | その技が当たれる段数の上限として働くと読める | [2024.05](../patch-notes/battle-change/202405.md#L225) MANON「トモエ・デリエール」、[2024.05](../patch-notes/battle-change/202405.md#L270) KIMBERLY「OD武神旋風脚」、[2024.05](../patch-notes/battle-change/202405.md#L271) KIMBERLY「OD荒鵺捻り」 |

いずれも「増加しました」「減少しました」としか書かれず、**具体的な数値は一度も出ていない。**

## 観測

- 地上やられなのに内部的にコンボカウント始動値が加算されていた、という不具合があった。始動値の加算は本来コンボの開始時にだけ起きるものだと読める。 — [2024.05](../patch-notes/battle-change/202405.md#L186) JAMIE「点辰」
- 加算値は段ごとに別々に設定されている。ジェイミーのしゃがみ強Kは初段の加算値だけを減らされた。 — [2024.05](../patch-notes/battle-change/202405.md#L161) JAMIE「しゃがみ強K」
- 上限値の増加は、コンボに組み込みやすくする方向の調整と同時に入っている。 — [2024.05](../patch-notes/battle-change/202405.md#L271) KIMBERLY「OD荒鵺捻り」
- **1つの技で加算値と上限値を同時に動かすこともある。** JPのヴィリーナは初段のコンボカウント上限値を増加、初段のコンボカウント加算値を減少。上限を上げて繋げやすくしつつ、加算値を下げて後続の伸びを抑える、という向き。 — [2024.09.24](../patch-notes/battle-change/20240924.md#L87) JP「ヴィリーナ」
