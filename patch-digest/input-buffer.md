# 先行入力

行動可能になる前の入力を繰り越して受け付ける仕組み。受付は状況ごとに別々に設定されている。コマンドが崩れるまでの猶予は別概念で、[入力保持フレーム](input-hold.md)に分けてある。

## 猶予フレーム

| 状況                       | 猶予                                       | 出典                                                       |
| -------------------------- | ------------------------------------------ | ---------------------------------------------------------- |
| 前方ステップ・後方ステップ | 4F → 7F                                    | [2023.09.27](../patch-notes/battle-change/20230927.md#L8)  |
| 起き上がり                 | 4F → 7F                                    | [2023.12.01](../patch-notes/battle-change/20231201.md#L10) |
| ガード後のリバーサル       | ガード硬直の長さによって変動(値の記載なし) | [2024.02.27](../patch-notes/battle-change/20240227.md#L46) |
| ドライブインパクト         | 5F → 10F                                   | [2024.05](../patch-notes/battle-change/202405.md#L86)      |

## 受付の範囲

- 時間停止演出中も入力を受け付ける。ドライブラッシュ発動時とSA発動時の両方が対象。 — [2023.07.24](../patch-notes/battle-change/20230724.md#L7) 全ファイター共通「ドライブパリィ」
- 先行入力の受付タイミング中にドライブパリィを入力し、行動可能になる前にパリィ入力を解除すると、中Kが暴発していた(修正済)。クラシックのパリィが中P+中Kであるため、解除の順序で中Kだけが残ったと読める。 — [2023.07.24](../patch-notes/battle-change/20230724.md#L7) 全ファイター共通「ドライブパリィ」
- アシストコンボにも先行入力がある。特定状況下で効かなくなる不具合、および1回の入力で2段目まで発動してしまう不具合があった(いずれも修正済)。 — [2023.07.24](../patch-notes/battle-change/20230724.md#L9) 全ファイター共通「アシストコンボの初段」
- **アシストコンボの入力受付タイミングは、アシストコンボごとに個別に設定されている。** 早すぎて暴発するもの、受付幅が短くて出しづらいものがあったため、個別に調整された。 — [2023.09.27](../patch-notes/battle-change/20230927.md#L7) 全ファイター共通「アシストコンボ」
- **必殺技キャンセルを受け付けている間はアシストコンボも受け付ける。** 受付幅が短く攻撃持続部分でキャンセルできないものがあったための変更。この影響で、入力が遅れるとアシストコンボが連続ヒットしなくなる可能性がある、と注記されている。 — [2023.09.27](../patch-notes/battle-change/20230927.md#L7) 全ファイター共通「アシストコンボ」
- アシストコンボ入力を途中で止めて、最速で同強度を出そうとした際に先行入力が効かない不具合、および別強度を出そうとした際に正しく発動しない不具合があった(いずれも修正済)。 — [2023.09.27](../patch-notes/battle-change/20230927.md#L7) 全ファイター共通「アシストコンボ」
  - 同じ形の不具合がエドの初段(立ち強P)で残っていた(修正済)。 — [2024.06.26](../patch-notes/battle-change/20240626.md#L101) ED「アシストコンボ3」
- **連打キャンセルが可能な間はアシストコンボの2段目も受け付ける、という揃え方をした版がある。** 2024.06.26 でルークとマリーザのアシストコンボ1が対象。 — [2024.06.26](../patch-notes/battle-change/20240626.md#L17) LUKE「アシストコンボ1」、[2024.06.26](../patch-notes/battle-change/20240626.md#L36) MARISA「アシストコンボ1」
- **アシストコンボ中にバーンアウトして、再度同じアシストコンボの初段を出し直した際、2段目以降が継続しない不具合があった(修正済)。** 出し直しの契機が2通り区別されている。**先行入力**で出した場合(キンバリー・マノン)と、**硬直終了と同時**に出した場合(ルーク・マノン・ジュリ・JP・ダルシム)。 — [2024.09.24](../patch-notes/battle-change/20240924.md#L19) 全ファイター共通「アシストコンボ(先行入力)」、[2024.09.24](../patch-notes/battle-change/20240924.md#L20) 全ファイター共通「アシストコンボ(硬直終了と同時)」
- アシストコンボの入力受付**開始**タイミングが想定より1F遅くなっていた(修正済)。この影響で、春麗とキンバリーはジャンプキャンセルと同時にボタンを押下するとアシストコンボが継続しなかった。 — [2023.12.01](../patch-notes/battle-change/20231201.md#L7) 全ファイター共通「アシストコンボ」
- **必殺技キャンセルにも先行入力の受付タイミングがある。** ブランカはSA2発動中にそれが早くなってしまう不具合があった。 — [2023.12.01](../patch-notes/battle-change/20231201.md#L67) BLANKA「立ち強P」、[2023.12.01](../patch-notes/battle-change/20231201.md#L69) BLANKA「立ち中K」
- 相手がSAを発動した際、暗転直後に特定の技を入力すると暗転終了時に技が発動してしまう不具合があった(修正済)。 — [2023.12.01](../patch-notes/battle-change/20231201.md#L10) 全ファイター共通「起き上がりの先行入力コンボ」
- **ジャストパリィ後にダウンを奪うと、相手の起き上がりに先行入力が効かなくなる不具合があった(修正済)。** ジャストパリィを経由したかどうかが、その後のダウンから起き上がる側の先行入力に影響しうる、という形の不具合。サーバーメンテナンスで修正されており、バトル変更リストには載っていない。 — [2024.12.07](../patch-notes/20241207.md) 公式Xの告知
- **ガード後のリバーサル先行入力受付時間は固定値ではなく、ガード硬直の長さによって変動する。** ドライブリバーサル等の一部の攻撃にこの設定が反映されていなかった(修正済)。変動の式や範囲は書かれていない。 — [2024.02.27](../patch-notes/battle-change/20240227.md#L46) 全ファイター共通「先行入力」
- ドライブインパクトの先行入力受付時間は 5F → 10F。演出発生時以外でも硬直終了直後に動きやすいように、が理由。 — [2024.05](../patch-notes/battle-change/202405.md#L86) 全ファイター共通「ドライブインパクト」
  - **この受付時間は、アーマーで攻撃を受け止めた後に相手へ攻撃がヒットしなかった場合でも通常時と同じであるのが正。** 短くなる不具合があった(修正済)。 — [2025.02.05](../patch-notes/battle-change/20250205.md#L8) 全ファイター共通「ドライブインパクト」
- 起き上がり時のドライブリバーサルは、早めに入力してボタンを押し続けることで確実に発動させられる。 — [2024.05](../patch-notes/battle-change/202405.md#L89) 全ファイター共通「ドライブリバーサル（起き上がり時）」
- **技ごとの先行入力は「硬直が解けるNF前から受け付ける」という形で設定される。** マノンの立ち強Kは硬直が解ける8F前から受け付けるようになった。 — [2024.05](../patch-notes/battle-change/202405.md#L220) MANON「立ち強K」
- 派生技には「次段への先行入力受付**開始**タイミング」が別に設定されている。ジェイミーの流酔拳・流酔脚は3段目への受付開始が 2F目 → 7F目 に遅くされた。強度によって開始フレームが違う不具合もあった。 — [2024.05](../patch-notes/battle-change/202405.md#L168) JAMIE「流酔拳」、[2024.05](../patch-notes/battle-change/202405.md#L172) JAMIE「中/強流酔拳」
- 技ごとの先行入力受付時間の例。マリーザのファルクスクラッシュ 5F → 9F、ODクアドリガ 5F → 10F。 — [2024.05](../patch-notes/battle-change/202405.md#L314) MARISA「ファルクスクラッシュ」、[2024.05](../patch-notes/battle-change/202405.md#L317) MARISA「ODクアドリガ」
- **飛び道具をジャストパリィすると、ステップの入力がリセットされていた**(変更済)。ジャストパリィ直後のステップとドライブラッシュの入力に影響がある、と明記されている。パリィドライブラッシュの項に書かれた変更。 — [2024.06.26](../patch-notes/battle-change/20240626.md#L7) 全ファイター共通「パリィドライブラッシュ」
