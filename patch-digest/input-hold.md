# 入力保持フレーム

コマンド入力がリセットされるまでの時間。[先行入力](input-buffer.md)とは別の概念で、こちらはコマンドが崩れるまでの猶予を指す。フレーム表に載っていない。

原文による定義。

> 入力保持フレームとは、コマンド入力がリセットされるまでの時間です。例えば「↓↘→↓↘→」であれば、最初の↓から次の↘までの入力保持フレームは9Fとなっています。この間に10Fが経過すると最初の↓入力はリセットされるため、続けて最後まで入力したとしてもSAが発動しません。

— [2023.09.27](../patch-notes/battle-change/20230927.md#L9) 全ファイター共通「コマンド入力の保持フレーム」

呼び方は版によって「コマンドの保持フレーム」「コマンド入力の保持フレーム」「入力保持フレーム」と揺れる。同じものを指す。

## 変更

- 意図しないSAの暴発を緩和する目的で、`↓↘→↓↘→` と `↓↙←↓↙←` のSAコマンドの入力保持フレームを短くした。変更後の値は書かれていない。以前より素早く入力しないとSAが発動しないことがある、と明記されている。 — [2023.09.27](../patch-notes/battle-change/20230927.md#L9) 全ファイター共通「コマンド入力の保持フレーム」
- ザンギエフのボルシチダイナマイトは、ジャンプ攻撃を出そうとした際の暴発が多かったため、通常版のみ 20F → 12F。 — [2023.09.27](../patch-notes/battle-change/20230927.md#L207) ZANGIEF「ボルシチダイナマイト」
