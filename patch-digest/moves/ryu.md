# リュウ

## モダン操作

- [2023.07.24](../../patch-notes/battle-change/20230724.md#L80) (M) アシストボタンを押下していると、手動入力で一部のOD必殺技が出せなくなっていた現象を修正。対象は空中竜巻旋風脚。

## ドライブインパクト

- [2023.07.24](../../patch-notes/battle-change/20230724.md#L81) 不要なコンボ補正が入っており、特定状況下でダメージが下がるようになっていた点を修正。

## OD昇龍拳

- [2024.02.27](../../patch-notes/battle-change/20240227.md#L92) 初段のヒット効果を**のけぞりから吹き飛びやられに変更**。

## しゃがみ強P

- [2023.09.27](../../patch-notes/battle-change/20230927.md#L135) 攻撃持続の2F目がヒットした際にモーションが戻ってしまう不具合を修正。
- [2024.05](../../patch-notes/battle-change/202405.md#L534) 攻撃持続2F目以降のダメージを1F目と同じ800にした。SAゲージ増加量 1000 → 1200、ガード時のドライブゲージ減少量 -6000 → -7500、パニッシュカウンター時のドライブゲージ減少量 -8000 → -10000。

## 鎖骨割り(→+中P)

- [2023.09.27](../../patch-notes/battle-change/20230927.md#L139) バーンアウト中のドライブゲージ増加量、2段目 1250 → 625。既知の不具合として、2段目のみを当てた場合に中段判定になるがその場合の増加量が上段相当の625のままだと明記された。
- [2023.12.01](../../patch-notes/battle-change/20231201.md#L54) バーンアウト中の相手に**中段判定の**2段目をガードさせた際の相手のドライブゲージ増加量 625 → 1250。「初段を空振りすると2段目が中段判定となります」と条件が明記されている。前版の既知の不具合が解消した。
- [2024.05](../../patch-notes/battle-change/202405.md#L536) ヒット時の硬直差 +2F → +3F、ガード時の硬直差 -3F → -1F。

## 不破三連撃(中P＞弱K＞強K)

- [2023.09.27](../../patch-notes/battle-change/20230927.md#L136) 最終段パニッシュカウンター時のドライブゲージ減少量 0 → 10000。2段目パニッシュカウンター時に相手のドライブゲージが2000増加していたため、2000減少するよう修正。
- [2024.05](../../patch-notes/battle-change/202405.md#L540) 2段目空振り時に3段目が発動しないようにした。3段目ヒット時に電刃錬気でキャンセル可能にした(クラシックは↓+P、モダンは↓+攻撃)。2段目ガード時の硬直差 -7F → -4F。

## 上段二連撃(強P＞強K)

- [2023.09.27](../../patch-notes/battle-change/20230927.md#L137) パニッシュカウンター時のドライブゲージ減少量 0 → 10000。
- [2024.05](../../patch-notes/battle-change/202405.md#L541) 2段目ヒット時に電刃錬気でキャンセル可能にした(クラシックは↓+P、モダンは↓+攻撃)。
- [2024.05](../../patch-notes/battle-change/202405.md#L542) クラシック操作のみ、強Pとの同時押しでは2段目が発動しないようにした。

## 鳩尾砕き(→+強P)

- [2024.02.27](../../patch-notes/battle-change/20240227.md#L93) 2〜18Fの**ガード待機判定**を攻撃判定の先端まで拡大。原文に定義があり、ガード待機判定の範囲内にいる相手が後ろを入力した時、相手は後退できずにガードモーションを取る。
- [2024.05](../../patch-notes/battle-change/202405.md#L537) **始動補正を撤廃。** ガード時の硬直差 +1F → +3F、初段ヒット時の相手ののけぞり時間 15F → 25F(相手の攻撃と相打ちした際などに影響)。

## 共通調整: バーンアウト中のドライブゲージ増加量

- [2023.09.27](../../patch-notes/battle-change/20230927.md#L139) ジャンプ中Pの2段目: 1500 → 750。鎖骨割りの2段目: 1250 → 625。**既知の不具合**として、鎖骨割りは2段目のみを当てた場合に中段判定になるが、その場合のドライブゲージ増加量が上段相当の625のままだと明記。次回アップデートで対応予定とされた。

## 共通調整: ジャストパリィのゲージ増加量

- [2023.09.27](../../patch-notes/battle-change/20230927.md#L140) 対象はジャンプ中P、鎖骨割り、鳩尾砕き、かかと落とし、【OD】昇龍拳、【中/強/OD】竜巻旋風脚、【SA1】真空波動拳、【SA3/CA】真・昇龍拳。値の記載なし。

## 共通調整: 後方の相手にヒットする攻撃の修正

- [2023.09.27](../../patch-notes/battle-change/20230927.md#L141) 対象は立ち弱K、不破三連撃の2段目、【SA3/CA】真・昇龍拳の最終段。

## 電刃錬気版の発動条件

- [2024.02.27](../../patch-notes/battle-change/20240227.md#L98) 電刃錬気版。攻撃判定と相殺判定を前方に拡大。ガードバックを縮小、OD版のダメージ 600 → 1000、攻撃持続終了から硬直終了まで移動量を縮小。
- [2024.05](../../patch-notes/battle-change/202405.md#L545) 弱/中版。ヒットバックを縮小。
- [2024.05](../../patch-notes/battle-change/202405.md#L546) 電刃錬気版。攻撃発生 21F → 20F、ヒット/空振り時の硬直 18F → 19F。攻撃持続1F目と2F目以降をガードさせた際に硬直が大きく変わっていた不具合を修正。
