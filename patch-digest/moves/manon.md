# マノン

## ダイナミック操作

- [2024.12.02](../../patch-notes/battle-change/20241202.md#L136) (M) ダイナミック操作時、バーンアウト中に←+EXボタンでデガジェが発動できなくなっていた不具合を修正。

## 【通常/OD】ランヴェルセ(↓↘→+P or PP)

- [2023.09.27](../../patch-notes/battle-change/20230927.md#L46) メダルLv3/Lv4の時のみ、ヒット後の硬直差が1F遅くなってしまっていた不具合を修正。
- [2024.12.02](../../patch-notes/battle-change/20241202.md#L141) ヒット時のSAゲージ増加量がメダルレベルに応じて変化するようにした。レベル1〜2：2150(変更なし) / レベル3〜4：3150 / レベル5：4150。
- [2024.12.02](../../patch-notes/battle-change/20241202.md#L142) フェイント動作の硬直を全強度2F短縮。

## 共通調整: 後方の相手にヒットする攻撃の修正

- [2023.09.27](../../patch-notes/battle-change/20230927.md#L49) 対象は立ち弱K、【SA3/CA】バ・ド・ドゥ。

## 共通調整: ジャストパリィのゲージ増加量

- [2023.09.27](../../patch-notes/battle-change/20230927.md#L50) 対象は【弱/中】デガジェ、ロン・ポワン、【SA2】エトワール。値の記載なし。

## モダン操作

- [2024.05](../../patch-notes/battle-change/202405.md#L213) (M) ↓↙←+攻撃でデガジェが発動できるようにした。コマンド投げのマネージュ・ドレとコマンドが重複するため以前はマネージュ・ドレのみ発動していたが、各強度のデガジェを出せないデメリットが大きいと判断された。この変更に伴いマネージュ・ドレのコマンド成立条件も変わっており、そちらはクラシック操作にも影響する。

## アシストコンボ

- [2024.05](../../patch-notes/battle-change/202405.md#L214) (M) アシストコンボ2。バーンアウト中の内容が追加された。
- [2024.05](../../patch-notes/battle-change/202405.md#L215) (M) アシストコンボ3。基本とバーンアウト状態で内容が分かれるようになった。
- [2024.09.24](../../patch-notes/battle-change/20240924.md#L51) (M) アシストコンボ2。SAゲージ0の時の内容を「立ち中K＞ODロン・ポワン＞(中)デガジェ」に変更。
- [2024.09.24](../../patch-notes/battle-change/20240924.md#L19) (M) アシストコンボ2。バーンアウトして先行入力で初段を出し直すと2段目以降が継続しない不具合を修正。全ファイター共通の該当キャラの1つ。詳細は [input-buffer.md](../input-buffer.md)。
- [2024.09.24](../../patch-notes/battle-change/20240924.md#L20) (M) アシストコンボ3。バーンアウトして硬直終了と同時に初段を出し直すと2段目以降が継続しない不具合を修正。全ファイター共通の該当キャラの1つ。詳細は [input-buffer.md](../input-buffer.md)。

## ウチマタ(後ろ投げ)

- [2024.05](../../patch-notes/battle-change/202405.md#L216) ヒットさせた後の間合いを遠くした。

## ドライブインパクト

- [2023.09.27](../../patch-notes/battle-change/20230927.md#L44) 相手のドライブインパクトに対して1F遅れて発動した際、相殺してしまっていた不具合を修正。
- [2024.05](../../patch-notes/battle-change/202405.md#L217) マノン同士で同時に行った際に相殺が発生しないことがあった不具合を修正。

## 立ち中P

- [2024.05](../../patch-notes/battle-change/202405.md#L218) ア・テールへの派生可能タイミングを 7〜13F → 11〜13F に調整。

## 立ち中K

- [2024.05](../../patch-notes/battle-change/202405.md#L219) ヒットバックを縮小。

## 立ち強K

- [2024.05](../../patch-notes/battle-change/202405.md#L220) **硬直が解ける8F前から先行入力を受け付けるようにした。**
- [2024.12.02](../../patch-notes/battle-change/20241202.md#L137) ヒット時の硬直差 -2F → +1F。パニッシュカウンター時の硬直差は変化なし。

## しゃがみ弱P

- [2024.05](../../patch-notes/battle-change/202405.md#L221) ヒット時の硬直差 +2F → +3F。

## しゃがみ中P

- [2024.05](../../patch-notes/battle-change/202405.md#L222) 空振り時のみ21〜22Fのやられ判定を前方に拡大。

## しゃがみ弱K

- [2024.05](../../patch-notes/battle-change/202405.md#L223) 攻撃判定を下方向に縮小。足元無敵の技に当たらないようにするための調整、と注記されている。ヒットバック/ガードバックを縮小。

## しゃがみ中K

- [2024.05](../../patch-notes/battle-change/202405.md#L224) ヒット時の硬直差 +2F → +3F、ヒットバックを縮小。

## トモエ・デリエール(↘+強K)

- [2024.05](../../patch-notes/battle-change/202405.md#L225) **コンボカウント上限値を増加。**

## ア・テール(中P＞中K)

- [2024.05](../../patch-notes/battle-change/202405.md#L226) クラシック操作のみ、中Pとの同時押しでは発動しないようにした。
- [2024.12.02](../../patch-notes/battle-change/20241202.md#L138) 2段目のドライブゲージ増加量 1000 → 2500。

## アン・オー(←+中K＞中K)

- [2024.02.27](../../patch-notes/battle-change/20240227.md#L69) ドライブラッシュの慣性が強く残るようにした。
- [2024.05](../../patch-notes/battle-change/202405.md#L227) 初段のガードバックを縮小。2段目空中ヒット時のヒット効果を地面バウンドに変更。2段目にコンボ中の相手にのみヒットする攻撃判定を追加し、上方向にいる相手に当たりやすくした。

## レベランス(←+強P)

- [2024.05](../../patch-notes/battle-change/202405.md#L228) ガード時の硬直差 -3F → +1F、ヒットバックを縮小。

## グラン・フェッテ(↓↘→+P＞K)

- [2024.05](../../patch-notes/battle-change/202405.md#L229) 通常版。パニッシュカウンター時にカメラの揺れを追加。
- [2024.05](../../patch-notes/battle-change/202405.md#L230) OD版。攻撃発生 11F → 10F。
- [2024.12.02](../../patch-notes/battle-change/20241202.md#L143) 通常版。ヒット時の吹き飛び距離を減らした。特定間合いで中デガジェが届かないケースの緩和、と方針側にある。

## ロン・ポワン(↓↘→+K)

- [2023.09.27](../../patch-notes/battle-change/20230927.md#L45) 強版2段目のパニッシュカウンター時のダメージ設定が誤っていたため 600 → 480。あわせて強/OD版のガード時に動作の終わり際をキャンセルできてしまう不具合を修正。
- [2024.05](../../patch-notes/battle-change/202405.md#L231) 通常版。2段目のみSA3/CAでキャンセル不可にした。
- [2024.05](../../patch-notes/battle-change/202405.md#L232) 強版。2段目空中ヒット時の横方向への吹き飛びを減少。
- [2024.05](../../patch-notes/battle-change/202405.md#L233) OD版。初段をSA2/SA3/CAでキャンセル可能にした。ダメージ配分 400+400 → 500+300(2段目のみヒット時は400のまま)。地上の相手にのみヒットする攻撃判定を前方に拡大。
- [2025.02.05](../../patch-notes/battle-change/20250205.md#L16) 通常/OD版。相手にパリィされた際にSAキャンセルができなかった不具合を修正。

## 【通常/OD】マネージュ・ドレ(→↘↓↙←+P or PP)

- [2024.05](../../patch-notes/battle-change/202405.md#L234) コマンドの保持フレームを全体的に短くした。`↘↓↙←` 入力ではコマンドが成立しないようにし、前入力の後にニュートラルや後ろを経由した際にも成立しないようにした。モダンのデガジェ追加に伴う変更だが、クラシックにも影響する。
- [2024.12.02](../../patch-notes/battle-change/20241202.md#L139) ヒット時のSAゲージ増加量がメダルレベルに応じて変化するようにした。レベル1〜2：3000(変更なし) / レベル3〜4：4000 / レベル5：5000。

## 【強】デガジェ(↓↙←+強K)

- [2024.12.02](../../patch-notes/battle-change/20241202.md#L140) ドライブゲージ増加量 2000 → 3000。

## 【SA1】アラベスク

- [2023.09.27](../../patch-notes/battle-change/20230927.md#L47) 一部の技に対して発動した際にお互いの攻撃が空振りやすくなっていたため、攻撃がヒットするまでは相手をすり抜けないように修正。
- [2023.09.27](../../patch-notes/battle-change/20230927.md#L48) バーンアウト中の相手にガードさせた際の、相手のドライブゲージ増加量: 1250 → 2500。
- [2024.05](../../patch-notes/battle-change/202405.md#L235) コンボ中の相手にのみヒットする攻撃判定を追加し、上方向にいる相手に当たりやすくした。動作1F目が完全無敵だったのを打撃・投げ無敵に修正。

## 【SA2】エトワール

- [2024.02.27](../../patch-notes/battle-change/20240227.md#L70) 初段と2段目が空中ヒットした際の吹き飛びを変更し、以降の攻撃が当たりやすくした(ヒット時の状況が以前と異なる)。2段目ヒット後に3段目以降が当たらなかった場合の相手のダウン時間を延長し、反撃を受けにくくした。
- [2024.05](../../patch-notes/battle-change/202405.md#L236) 最終段のダメージ 850 → 950。3段目以降にコンボ中の相手にのみヒットする攻撃判定を追加し、下方向にいる相手に当たりやすくした。58F〜80Fまで押し合い判定を上方向に拡大。

## 【SA3/CA】パ・ド・ドゥ

- [2024.05](../../patch-notes/battle-change/202405.md#L237) **メダルLvに応じてダメージが変動するようにした。** SA3が Lv1:4000 / Lv2:4100 / Lv3:4200 / Lv4:4400 / Lv5:4600、CAが Lv1:4500 / Lv2:4600 / Lv3:4700 / Lv4:4900 / Lv5:5100。空振り時の9F〜62Fのやられ判定を前方に拡大。
