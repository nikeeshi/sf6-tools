# 春麗

## 気功拳

- [2023.07.24](../../patch-notes/battle-change/20230724.md#L105) モダン操作時の溜め値だけがクラシックと異なっていたため、クラシックに合わせた。溜めの完成時間 45F → 50F、コマンドの保持フレーム 0F → 10F。変更後の値がクラシックの値で、クラシック側は変わっていない。

## OD気功拳

- [2023.07.24](../../patch-notes/battle-change/20230724.md#L105) モダン操作時の溜め値だけがクラシックと異なっていたため、クラシックに合わせた。コマンドの保持フレーム 0F → 10F。溜めの完成時間は変更されていない。変更後の値がクラシックの値で、クラシック側は変わっていない。

## 前投げ / 後ろ投げ / 空中投げ

- [2023.07.24](../../patch-notes/battle-change/20230724.md#L106) 投げの動作中に溜め方向が入れ替わってしまう現象を修正。

## 行雲流水

- [2023.07.24](../../patch-notes/battle-change/20230724.md#L107) 特定の技を当てて行雲流水でキャンセルする際、「行雲流水⇒K」の入力を素早く行うと覇山蹴が暴発する現象を修正。

## ジャンプ強P

- [2023.09.27](../../patch-notes/battle-change/20230927.md#L191) ダメージは地上ヒット時800・空中ヒット時500だが、空中でカウンター/パニッシュカウンターした時のダメージが地上ヒット準拠の960になっていたため、**600に修正**。空中ヒットの値を基準に1.2倍するのが正しい、と読める。

## 蓮掌(↓↙←+P＞強P)

- [2023.09.27](../../patch-notes/battle-change/20230927.md#L192) 3〜28F間の頭部のやられ判定が意図せず縮小していたため拡大。初段空振り時に2段目が上段判定になっていたため、**空振り時は2段目が中段判定**になるよう修正。初段ヒット時は2段目が上段判定。
- [2023.09.27](../../patch-notes/battle-change/20230927.md#L198) バーンアウト中の相手にガードさせた際の相手のドライブゲージ増加量、2段目: 2500 → 1250。**既知の不具合**として、2段目のみを当てた場合は中段判定になるが、その場合の増加量が上段相当の1250のままだと明記。次回アップデートで対応予定とされた。

## 【OD】天昇脚(↓↓+KK)

- [2023.09.27](../../patch-notes/battle-change/20230927.md#L193) 2段目ヒット時に位置が入れ替わると、着地後に春麗が大きく移動してしまう不具合を修正。

## 【SA1】気功掌

- [2023.09.27](../../patch-notes/battle-change/20230927.md#L194) 空中の相手にヒットした時、最終段以外でKOできなかった不具合を修正。

## 【SA2】鳳翼扇

- [2023.09.27](../../patch-notes/battle-change/20230927.md#L195) アシストコンボで発動した後、特定のタイミングで次の入力を行うとアシストコンボが途切れてしまう不具合を修正。

## 【SA3】蒼天乱華

- [2023.09.27](../../patch-notes/battle-change/20230927.md#L196) 2段目以降をガードさせた際のドライブゲージ減少量が0だったため修正。SA3: 初段 7500 → 6500、2〜3段目 0 → 500。CA: 初段 10000 → 9000、2〜3段目 0 → 500。

## 共通調整: バーンアウト中の削りダメージ

- [2023.09.27](../../patch-notes/battle-change/20230927.md#L197) 【中】スピニングバードキック: 275 → 300。

## 共通調整: 後方の相手にヒットする攻撃の修正

- [2023.09.27](../../patch-notes/battle-change/20230927.md#L199) 対象は百裂脚、百裂連脚、覇山蹴、スピニングバードキック、【SA3/CA】蒼天乱華。

## 共通調整: ジャストパリィのゲージ増加量

- [2023.09.27](../../patch-notes/battle-change/20230927.md#L200) 対象はしゃがみ強P、蓮掌、百裂脚、百裂連脚、空中百裂脚、スピニングバードキック、ドライブリバーサル、【SA1】気功掌、【SA1】空中気功掌、【SA2】鳳翼扇、【SA3/CA】蒼天乱華。値の記載なし。
