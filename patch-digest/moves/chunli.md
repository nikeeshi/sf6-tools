# 春麗

## 気功拳

- [2023.07.24](../../patch-notes/battle-change/20230724.md#L105) モダン操作時の溜め値だけがクラシックと異なっていたため、クラシックに合わせた。溜めの完成時間 45F → 50F、コマンドの保持フレーム 0F → 10F。変更後の値がクラシックの値で、クラシック側は変わっていない。

## OD気功拳

- [2023.07.24](../../patch-notes/battle-change/20230724.md#L105) モダン操作時の溜め値だけがクラシックと異なっていたため、クラシックに合わせた。コマンドの保持フレーム 0F → 10F。溜めの完成時間は変更されていない。変更後の値がクラシックの値で、クラシック側は変わっていない。

## 前投げ / 後ろ投げ / 空中投げ

- [2023.07.24](../../patch-notes/battle-change/20230724.md#L106) 投げの動作中に溜め方向が入れ替わってしまう現象を修正。

## 行雲流水

- [2023.07.24](../../patch-notes/battle-change/20230724.md#L107) 特定の技を当てて行雲流水でキャンセルする際、「行雲流水⇒K」の入力を素早く行うと覇山蹴が暴発する現象を修正。
