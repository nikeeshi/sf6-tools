# エドモンド本田

## しゃがみ弱P(連キャン版)

- [2023.07.24](../../patch-notes/battle-change/20230724.md#L87) 1F目を空キャンセルできてしまう不具合を修正。

## 千秋楽(SA3)

- [2023.07.24](../../patch-notes/battle-change/20230724.md#L88) パリィ成立時のドライブゲージ増加量が他キャラクターと比べて非常に高かったため、適正な値に修正。
- [2024.05](../../patch-notes/battle-change/202405.md#L955) ヒット演出中のダメージ配分を変更し、**コンボに組み込んだ際の最低保証ダメージが50%以下にならないようにした。**

## 立ち強P

- [2023.09.27](../../patch-notes/battle-change/20230927.md#L147) ドライブラッシュから発動する際、肩屋入り状態だと通常時よりも移動量が大きくなってしまう不具合を修正。
- [2024.05](../../patch-notes/battle-change/202405.md#L934) パニッシュカウンター時のダウン時間を12F増加。
- [2024.12.02](../../patch-notes/battle-change/20241202.md#L408) ヒット時の硬直差 -1F → +1F。方針側に、通常版の大砲が連続ヒットするようになり打撃のリターンが上がった、と書かれている。

## しゃがみ強P

- [2023.09.27](../../patch-notes/battle-change/20230927.md#L148) ドライブラッシュから発動する際、肩屋入り状態だと通常時よりも移動量が小さくなってしまう不具合を修正。

## 【SA2】スーパー鬼無双

- [2023.12.01](../../patch-notes/battle-change/20231201.md#L60) (M) モダン操作のSPボタンで発動する時のみ、溜め時間が5F長くなってしまっていた不具合を修正。
- [2024.05](../../patch-notes/battle-change/202405.md#L954) ドライブラッシュを使用したコンボに組み込んだ際に、演出中にドライブゲージが回復していた不具合を修正。
- [2024.09.24](../../patch-notes/battle-change/20240924.md#L132) 頭突き部分のヒットバックや張り手部分の攻撃判定を調整して動作途中で空振りしにくくし、頭突き部分のダウン時間を延長して以降の攻撃がヒットしなかった際に反撃を受けないようにした。
- [2024.12.02](../../patch-notes/battle-change/20241202.md#L413) 頭突き部分ヒット後、張り手部分最終段まで全身飛び道具無敵に変更。

## 共通調整: バーンアウト中のドライブゲージ増加量

- [2023.09.27](../../patch-notes/battle-change/20230927.md#L149) 力足: 2500 → 5000。払い蹴り: 3000 → 6000。地鎮: 2500 → 5000。スーパー百貫落としの2段目: 4000 → 8000。

## 共通調整: ジャストパリィのゲージ増加量

- [2023.09.27](../../patch-notes/battle-change/20230927.md#L150) 対象は【OD】スーパー頭突き、鉄砲、大砲、百裂張り手、【SA2】スーパー鬼無双、【SA3/CA】千秋楽。値の記載なし。

## アシストコンボ

- [2024.05](../../patch-notes/battle-change/202405.md#L930) (M) アシストコンボ3。バーンアウト中の内容が追加された。

## 俵投げ(後ろ投げ)

- [2024.05](../../patch-notes/battle-change/202405.md#L931) 画面端を背負った状態でヒットさせた後の間合いを遠くした。

## 立ち中P

## 立ち中K

- [2024.05](../../patch-notes/battle-change/202405.md#L933) 動作7F目以降、足元のやられ判定を縮小。

## しゃがみ中K

- [2024.05](../../patch-notes/battle-change/202405.md#L935) ヒット時の硬直差 +5F → +6F。

## しゃがみ強K

- [2024.05](../../patch-notes/battle-change/202405.md#L936) 後ろ側の攻撃判定が空中ヒットした際の吹き飛び時間を増加し、横方向の吹き飛びを縮小。

## ジャンプ中P

- [2024.05](../../patch-notes/battle-change/202405.md#L937) 空中ヒット時のヒット効果を**空中復帰 → 吹き飛びダウン**に変更。

## 連ね張り手(弱P＞中P)

- [2024.05](../../patch-notes/battle-change/202405.md#L938) クラシック操作のみ、中Kとの同時押しでは発動しないようにした。

## 地鎮(中P＞↘+強K)

- [2023.09.27](../../patch-notes/battle-change/20230927.md#L149) バーンアウト中のドライブゲージ増加量 2500 → 5000。
- [2024.05](../../patch-notes/battle-change/202405.md#L939) ヒット時に肩屋入りでキャンセル可能にした(クラシックは↓+強K、モダンは↓+中攻撃)。攻撃発生前の必殺技キャンセル可能タイミング 15F目 → 14F目。
- [2024.05](../../patch-notes/battle-change/202405.md#L940) クラシック操作のみ、強Pとの同時押しでは発動しないようにした。

## 百裂張り手(↓↙←+P)

- [2024.05](../../patch-notes/battle-change/202405.md#L941) 通常/肩屋入り版。2段目以降の攻撃判定を前方に拡大。
- [2024.05](../../patch-notes/battle-change/202405.md#L942) 肩屋入り版。しゃがみ弱K、立ち中K、しゃがみ中Kからキャンセル可能に変更。
- [2024.05](../../patch-notes/battle-change/202405.md#L943) 肩屋入りの中/強版。最終段地上ヒット時のヒットバックを縮小、最終段空中ヒット時の横方向の吹き飛びを縮小。

## スーパー頭突き(←溜め＞→+P)

- [2024.05](../../patch-notes/battle-change/202405.md#L944) 弱/中版。攻撃持続1〜4F目までのダメージ 1300 → 1400、ガード時の硬直差 -4 → -3、ガードバックを縮小、バーンアウト中のガードバックを拡大、攻撃持続4F目にコンボ中の相手にのみヒットする攻撃判定を付与、ガード後の前進距離を増加。
- [2024.05](../../patch-notes/battle-change/202405.md#L945) 強版。攻撃持続1〜4F目までのダメージ 1400 → 1500、ガード時の硬直差 -4 → -3、ガードバックを縮小(バーンアウト中のガードバックは以前のまま)、ガード後の前進距離を増加、相手との位置が入れ替わった際の前進距離を減少。

## スーパー百貫落とし(↓溜め＞↑K)

- [2023.09.27](../../patch-notes/battle-change/20230927.md#L149) 2段目のバーンアウト中のドライブゲージ増加量 4000 → 8000。
- [2024.05](../../patch-notes/battle-change/202405.md#L946) 通常版。2段目ヒット時に**後ろ受け身不可**に変更。2段目のガードバックを拡大、2段目ガード時の相手のドライブゲージ減少量 -8000 → -10000。
- [2024.05](../../patch-notes/battle-change/202405.md#L947) OD版。2段目ヒット時に後ろ受け身不可に変更。動作中にKボタンホールド(モダンは攻撃ボタン)で、強度に応じて2段目の発生が変化するようにした。2段目のコンボ中の相手にのみヒットする攻撃判定を上方向に拡大、2段目ガード時の硬直差 +1F → +2F。
- [2024.06.26](../../patch-notes/battle-change/20240626.md#L88) 共通調整「特定の対空技」。対空無敵があるのに空中投げに負けやすかったため、**OD版に投げ無敵を付与。5〜13F。** 原文は技名を「百貫落とし」と書いている。

## 鉄砲(↓↘→+K or KK＞P)

- [2024.05](../../patch-notes/battle-change/202405.md#L948) クラシック操作のみ、中Kまたは強Kとの同時押しでは発動しないようにした。
- [2024.05](../../patch-notes/battle-change/202405.md#L949) OD版。2段目の地上ヒット効果を**吹き飛びダウン → のけぞり**に変更。最終段への派生タイミングを1F早く、先行入力の受け付け時間 5F → 10F。調整方針側に、カウンターヒット時は+5Fとなりコンボが狙えるようになった、と書かれている。
- [2024.12.02](../../patch-notes/battle-change/20241202.md#L409) 通常/OD版。初段・2段目の攻撃判定を横方向に拡大、動作9〜14F・25〜28Fの腕部分のやられ判定を縮小、動作9〜33Fの足部分のやられ判定を縮小。方針側に、判定強化で中距離から触りやすくしガード時の展開も良くした、と書かれている。
- [2024.12.02](../../patch-notes/battle-change/20241202.md#L410) 通常版。初段・2段目のガードバックを拡大、ドライブゲージ増加量 1000×2 → 2000×2。
- [2024.12.02](../../patch-notes/battle-change/20241202.md#L411) OD版。2段目ガード時の硬直差 +2F → +3F、初段・2段目のガードバックを縮小。
