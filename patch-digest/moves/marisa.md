# マリーザ

## エンフォルド(スクトゥム中に2+P)

- [2023.07.24](../../patch-notes/battle-change/20230724.md#L38) (M) スクトゥムの反撃動作中、SPボタンをホールドしていても下方向を入力していると構えを継続しなくなっており、エンフォルドの入力が下方向を含むため発動しづらかった。反撃動作中にSPボタンをホールドしていれば、下方向を入れていても構えを継続するよう修正。
- [2024.05](../../patch-notes/battle-change/202405.md#L321) ヒット時の硬直差 +20F → +18F。

## モダン操作

- [2023.09.27](../../patch-notes/battle-change/20230927.md#L66) (M) 通常技・特殊技から前方向+SPボタンでグラディウスがキャンセルできなかった不具合を修正。

## カエルムアーク(垂直ジャンプ中に↓+強P)

- [2023.09.27](../../patch-notes/battle-change/20230927.md#L67) 後方の相手に当てた際、相手に与える硬直が大幅に長くなる不具合を修正。**ヒット時 27F → 19F、ガード時 23F → 15F**。あわせて、後方の相手にガードさせた際にバーンアウト中のみ相手の向きが逆になる不具合と、着地硬直を他の行動でキャンセルできる不具合を修正。

## ディマカイルス(↓↙←+P)

- [2023.09.27](../../patch-notes/battle-change/20230927.md#L68) ガード時のSAゲージ増加量がヒット時の1/2になっていない不具合を修正。
- [2025.02.05](../../patch-notes/battle-change/20250205.md#L28) OD版。SAキャンセルの先行入力受付開始タイミングを動作2F目 → 10F目に変更。`↓↙←↓↙←+PP` でODディマカイルスを発動した際に、派生の→+P入力でSA2が暴発しないようにするための調整、と注記されている。

## 【SA1 ホールド】マリーザジャベリン

- [2023.09.27](../../patch-notes/battle-change/20230927.md#L69) 攻撃持続5〜6F目のみ、カウンター/パニッシュカウンター時にダメージが増加してしまう不具合を修正。
- [2023.12.01](../../patch-notes/battle-change/20231201.md#L22) 特定のタイミングでホールドを解除すると、攻撃発生が1F早くなってしまう不具合を修正。
- [2024.05](../../patch-notes/battle-change/202405.md#L322) 当身成立時の攻撃判定を下方向に拡大。ドライブラッシュを使用したコンボに組み込んだ際に演出中にドライブゲージが回復していた不具合を修正。動作1F目が完全無敵だったのを打撃・投げ無敵に修正。
