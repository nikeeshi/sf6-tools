- [2024.02.27](../../patch-notes/battle-change/20240227.md#L153) 攻撃判定を前方に拡大。

## 【弱】蛇頭鞭(↓↘→+弱P)

- [2023.12.01](../../patch-notes/battle-change/20231201.md#L105) ジャストパリィされた際にA.K.I.の硬直が増加してしまう不具合を修正。

## 【OD】蛇軽功(アシスト+N+SP)

- [2023.12.01](../../patch-notes/battle-change/20231201.md#L108) (M) モダン操作では蛇軽功はニュートラル+SPボタンで発動するが、紫煙砲からのキャンセル版OD蛇軽功だけは方向キーがどこでも発動できていた。OD紫煙砲入力時にボタンを連打するとOD蛇軽功が暴発しやすかったため、キャンセル版もニュートラル限定に変更。
- [2024.02.27](../../patch-notes/battle-change/20240227.md#L154) (M) 紫煙砲が画面上に存在している状態で←+AUTO+SPを入力すると、OD版ではなく通常版の蛇軽功が発動していた不具合を修正。

## 毒破裂全般(2026.03.17)

- [2026.03.17](../../patch-notes/battle-change/20260317.md#L725) **毒破裂が発生した際の自身のドライブゲージ増加量を一律2000増やした。**

| 技                                    | 増加量      |
| ------------------------------------- | ----------- |
| 窮奇(強P＞強P)、紫煙追(紫煙砲中に→+P) | 3000 → 5000 |
| 弱・中蛇頭鞭、猛毒牙(悪鬼蛇行中にP)   | 2000 → 4000 |
| 強蛇頭鞭                              | 2500 → 4500 |
| OD紫煙追(OD紫煙砲中に→+P)、OD蛇頭鞭   | 0 → 2000    |

**ドライブラッシュをコンボに組み込んだ後に毒破裂が発生した際は、以前と変わらずドライブゲージは増加しない**、と注記されている。方針側に、毒破裂を効率よく発生させてドライブゲージを使いダメージを奪うサイクルを回しやすくする狙い、と書かれている。
