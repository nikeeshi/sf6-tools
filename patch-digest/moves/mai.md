# 舞

補足: **焔ストック**は舞固有のリソース。技名に `[強化版]` と付く版は焔ストックを消費した強化状態を指す。

## ジャンプ攻撃(モダン操作)

- [2025.06](../../patch-notes/battle-change/202506.md#L1001) (M) 通常時は 弱→ジャンプ弱P / 中→ジャンプ中P / 強→ジャンプ強K、アシストボタン入力時は 弱→ジャンプ弱K / 中→ジャンプ中K / 強→ジャンプ強P。

## 前歩き

- [2025.06](../../patch-notes/battle-change/202506.md#L1002) 動作の途中、ドライブゲージが増加しないタイミングがあった不具合を修正。

## 立ち強P

- [2025.06](../../patch-notes/battle-change/202506.md#L1003) ドライブゲージ増加量 3000 → 2000、ヒットバックを縮小。

## 立ち強K

- [2025.06](../../patch-notes/battle-change/202506.md#L1004) 空振り時の硬直 19F → 22F、攻撃持続終了〜硬直終了まで体部分のやられ判定を前方に拡大、ガードバックを縮小。方針側に、空振り時のリスクを増やし、ガードバック縮小でガード後にターンが入れ替わりやすくした、と書かれている。

## 立ち強K(2025.07.04)

- [2025.07.04](../../patch-notes/update-maintenance/20250704.json) 空振り時、硬直が解ける2F前を別のアクションでキャンセルできた不具合を修正。2025.06 で空振り時の硬直を 19F → 22F にした直後の修正。

## しゃがみ弱P

- [2025.06](../../patch-notes/battle-change/202506.md#L1005) 攻撃判定を上方向に拡大。

## しゃがみ強K

- [2025.06](../../patch-notes/battle-change/202506.md#L1006) 空振り時の硬直 22F → 25F。

## 【通常/OD】花蝶扇(↓↘→+P or PP)

- [2025.06](../../patch-notes/battle-change/202506.md#L1007) 攻撃判定発生時の飛び道具相殺判定を手前側に拡大。
- [2025.06](../../patch-notes/battle-change/202506.md#L1008) 通常版[通常/強化版]。足部分のやられ判定が消失するタイミングを硬直終了までに変更、腕部分のやられ判定が攻撃発生から27F間残るようにした。
- [2025.06](../../patch-notes/battle-change/202506.md#L1009) 通常版ホールド[通常/強化版]。3F目から足元に**飛び道具無敵のやられ判定**が発生するようにし、ホールド版が成立した19F以降〜硬直終了まで体部分のやられ判定を前方に拡大。
- [2025.06](../../patch-notes/battle-change/202506.md#L1010) 通常版ホールド / OD版 / OD強化版ホールド / OD乱れ花蝶扇。**跳ねた後の扇子からガード待機判定を削除。** 場に残る飛び道具にもガード待機判定が設定されうることが読める。
- [2025.06](../../patch-notes/battle-change/202506.md#L1011) OD版。ドライブパリィ/ジャストパリィした際のドライブゲージ増加量を、通常版 2500・2500 → 5000・5000、強化版 1250・1250・2500 → 2500・2500・5000。

## [通常/強化版]乱れ花蝶扇(↓↘→+PPホールド＞→+P)

- [2025.06](../../patch-notes/battle-change/202506.md#L1012) 3・4発目の扇子が1発だけ相殺した場合、扇子が1つになりヒット時も1つだけ跳ねるように変更。

## 龍炎舞(↓↙←+P)

- [2025.06](../../patch-notes/battle-change/202506.md#L1014) 中版。ドライブゲージ増加量 2000 → 3000。

## 【通常】飛翔龍炎陣(→↓↘+K)

- [2025.06](../../patch-notes/battle-change/202506.md#L1015) **コンボカウント上限値を増加。**

## 【通常/OD】ムササビの舞(前ジャンプ中に↓↙←+P or PP)

- [2025.06](../../patch-notes/battle-change/202506.md#L1016) [通常/強化版]。硬直中に攻撃を受けた際の姿勢をしゃがみ → 立ちに変更。
- [2025.06](../../patch-notes/battle-change/202506.md#L1017) [強化版]。焔ストックを所持している状態でジャンプ攻撃からずらし入力で発動した場合、通常版が発動していた不具合を修正。

## 【SA1】[通常/強化版]陽炎の舞(↓↘→↓↘→+P)

- [2025.06](../../patch-notes/battle-change/202506.md#L1018) **焔ストックが溜まるタイミングを攻撃判定発生と同時 → 硬直終了直前に変更。** 強化版発動時に焔ストックを消費していなかった不具合も修正。方針側に、ガードされてもストックが付与されるというメリットが残らないようにした、と書かれている。

## 【SA3/CA】不知火流・炎舞仇桜(↓↙←↓↙←+P)

- [2025.06](../../patch-notes/battle-change/202506.md#L1019) 非ロック版に**始動補正50%を追加。**

## 【中】[通常/強化版]龍炎舞(2025.10.15)

- [2025.10.15](../../patch-notes/battle-change/20251015.md#L86) 通常/強化版の2段目のみがヒットした際に20%の始動補正がかかっていた不具合と、通常版がコンボ中に2段目のみヒットした際に20%のコンボ補正がかかっていた不具合を修正。**補正は段ごとに持たれており、2段目単独ヒット時に初段の補正が誤って適用されうる**、と読める。

## 立ち強P(2025.12.16)

- [2025.12.16](../../patch-notes/battle-change/20251216.md#L82) ガード時のドライブゲージ減少量 5000 → 4000。方針側に、連係の起点や中継に使われやすくガードさせる機会が多いため、と書かれている。

## 立ち弱K(2025.12.16)

- [2025.12.16](../../patch-notes/battle-change/20251216.md#L83) 攻撃判定発生前に発生する足部分のやられ判定を、めくり攻撃に対して無敵にした。全ファイター共通のしゃがみ弱K調整と同じ内容が、舞は立ち弱Kにも入っている。

## 花蝶扇のパリィ時ドライブゲージ増加量(2025.12.16)

**舞の各種花蝶扇は、ジャスト/ノーマルパリィ時のドライブゲージ回復量がまとめて引き上げられた。** 方針側に、ジャストパリィ成功時もパリィ発動時のコストと差し引きでマイナスになる状況を減らし、ノーマルパリィでもある程度の回復量を担保して**バーンアウトを誘発しづらくする**狙い、と書かれている。特に弱花蝶扇(ホールド)と焔ストック所持時の通常花蝶扇は、1〜2段をノーマルパリィで受けるとドライブゲージが増加するようになった。

- [2025.12.16](../../patch-notes/battle-change/20251216.md#L84) 【通常】花蝶扇(ホールド)。ドライブパリィ時 2500・2500 → 5000・2500、ジャストパリィ時 2500・2500 → 5000・5000。
- [2025.12.16](../../patch-notes/battle-change/20251216.md#L85) 【OD】花蝶扇(ホールド)。ドライブパリィ/ジャストパリィ時 1400×2 → 2500×2。
- [2025.12.16](../../patch-notes/battle-change/20251216.md#L86) 乱れ花蝶扇。1〜2段目のジャストパリィ時 1200×2 → 2500×2、3〜4段目(落下部分)のジャストパリィ時 1150×2 → 5000×2。
- [2025.12.16](../../patch-notes/battle-change/20251216.md#L87) 【通常】[陽炎の舞]花蝶扇。ドライブパリィ/ジャストパリィ時 2500×2 → 3000×2。
- [2025.12.16](../../patch-notes/battle-change/20251216.md#L88) 【通常】[陽炎の舞]花蝶扇(ホールド)。ドライブパリィ時 1250×2・2500 → 2500×3、ジャストパリィ時 1250×2・2500 → 2500×2・5000。
- [2025.12.16](../../patch-notes/battle-change/20251216.md#L89) 【OD】[陽炎の舞]花蝶扇(ホールド)。1〜2段目のドライブパリィ/ジャストパリィ時 1200×2 → 2500×2、3〜4段目のジャストパリィ時 750×2 → 2500×2。
- [2025.12.16](../../patch-notes/battle-change/20251216.md#L90) [陽炎の舞]乱れ花蝶扇。1〜2段目のジャストパリィ時 1050×2 → 2500×2、3〜4段目のジャストパリィ時 750×2 → 2500×2。

## 【通常】[通常/強化版]必殺忍蜂(↓↘→+K)

- [2025.12.16](../../patch-notes/battle-change/20251216.md#L91) 相手が画面端にいる状態で技の硬直中に攻撃を受けると、画面中央より相手との距離が近くなってしまうことがある現象を修正。

## 前投げ(2025.12.16)

- [2025.12.16](../../patch-notes/battle-change/20251216.md#L92) 画面端でヒットさせた後の距離を近くした。方針側に、**距離が近くなることで前方ステップ＞後退という連係を行っても起き上がった相手の通常投げを避けられなくなり**、通常投げと無敵技の両方をケアしづらくなった、と書かれている。前方ステップ後の有利フレーム自体は変わっていない。

## ドライブリバーサル

- [2025.06](../../patch-notes/battle-change/202506.md#L1020) 持続中に攻撃判定が伸びないよう、3F目のリーチに合わせる形で1〜2F目の攻撃判定を拡大。
