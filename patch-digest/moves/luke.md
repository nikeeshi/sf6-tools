# ルーク

## モダン操作

- [2023.07.24](../../patch-notes/battle-change/20230724.md#L18) アシストボタンを押下していると、手動入力で一部のOD必殺技が出せなくなっていた現象を修正。対象はサンドブラスト、ライジングアッパー、フラッシュナックル、エアフラッシュナックル。

## ODアベンジャー

- [2023.07.24](../../patch-notes/battle-change/20230724.md#L19) 特定の技をアーマー判定で受け止めた際に不自然なヒットストップ差が出ていたため、アーマー判定のヒットストップ値を調整。

## 【OD】ノーチェイサー(↓↘→+KK＞P)

- [2023.09.27](../../patch-notes/battle-change/20230927.md#L23) ガード時のSAゲージ増加量がヒット時の半分になっていなかったため、500 → 600。

## 共通調整: バーンアウト中の削りダメージ

- [2023.09.27](../../patch-notes/battle-change/20230927.md#L24) 【弱】フラッシュナックル ジャスト版の2段目: 75 → 50。

## 共通調整: バーンアウト中のドライブゲージ増加量

- [2023.09.27](../../patch-notes/battle-change/20230927.md#L25) 【弱】フラッシュナックル ジャスト版の2段目: 0 → 500。フェイタルショット(↓↘→+PP＞PP): 0 → 500。**原文はこの行の変更箇所を「共通調整：ジャストパリィのゲージ増加量」としているが、本文はバーンアウト中のドライブゲージ増加量の話。原文側の見出しの誤り。**

## 共通調整: ジャストパリィのゲージ増加量

- [2023.09.27](../../patch-notes/battle-change/20230927.md#L26) 対象は【弱/中/強】フラッシュナックルのジャスト/最大溜め版、【OD】ライジングアッパー、【SA1】バルカンブラスト、【SA2】イレイザー。値の記載なし。

## ドライブインパクト
