# ルーク

## モダン操作

- [2023.07.24](../../patch-notes/battle-change/20230724.md#L18) (M) アシストボタンを押下していると、手動入力で一部のOD必殺技が出せなくなっていた現象を修正。対象はサンドブラスト、ライジングアッパー、フラッシュナックル、エアフラッシュナックル。

## ODアベンジャー

- [2023.07.24](../../patch-notes/battle-change/20230724.md#L19) 特定の技をアーマー判定で受け止めた際に不自然なヒットストップ差が出ていたため、アーマー判定のヒットストップ値を調整。

## 【OD】ノーチェイサー(↓↘→+KK＞P)

- [2023.09.27](../../patch-notes/battle-change/20230927.md#L23) ガード時のSAゲージ増加量がヒット時の半分になっていなかったため、500 → 600。
- [2024.05](../../patch-notes/battle-change/202405.md#L129) 通常/OD版。攻撃持続 7F → 10F、硬直 19F → 16F。

## 共通調整: バーンアウト中の削りダメージ

- [2023.09.27](../../patch-notes/battle-change/20230927.md#L24) 【弱】フラッシュナックル ジャスト版の2段目: 75 → 50。

## 共通調整: バーンアウト中のドライブゲージ増加量

- [2023.09.27](../../patch-notes/battle-change/20230927.md#L25) 【弱】フラッシュナックル ジャスト版の2段目: 0 → 500。フェイタルショット(↓↘→+PP＞PP): 0 → 500。**原文はこの行の変更箇所を「共通調整：ジャストパリィのゲージ増加量」としているが、本文はバーンアウト中のドライブゲージ増加量の話。原文側の見出しの誤り。**

## 共通調整: ジャストパリィのゲージ増加量

- [2023.09.27](../../patch-notes/battle-change/20230927.md#L26) 対象は【弱/中/強】フラッシュナックルのジャスト/最大溜め版、【OD】ライジングアッパー、【SA1】バルカンブラスト、【SA2】イレイザー。値の記載なし。

## しゃがみ中P

- [2024.02.27](../../patch-notes/battle-change/20240227.md#L52) 空振り時の硬直を3F増加。6〜24F目まで足元のやられ判定を拡大。19F目から腕のやられ判定を拡大。
- [2024.05](../../patch-notes/battle-change/202405.md#L116) **始動補正15%を追加。** 前方への攻撃判定を縮小。

## エアフラッシュナックル

- [2024.02.27](../../patch-notes/battle-change/20240227.md#L53) 高空で空振りした際の着地硬直を7F増加し、軌道を変更。16F目から動作終了まで足元のやられ判定を拡大。溜め版は変更なし。

## 【SA1】バルカンブラスト

- [2024.02.27](../../patch-notes/battle-change/20240227.md#L54) 1〜5Fの体部分のやられ判定を拡大。

## アシストコンボ

- [2024.05](../../patch-notes/battle-change/202405.md#L108) (M) アシストコンボ1。SAゲージ0の時とバーンアウト状態の時のコンボ内容が追加された。
- [2024.05](../../patch-notes/battle-change/202405.md#L109) (M) アシストコンボ2。ODフラッシュナックルの2段目からSA2へキャンセルするよう変更。SAゲージ2本未満の時とバーンアウト状態の時のコンボ内容が追加された。
- [2024.05](../../patch-notes/battle-change/202405.md#L110) (M) アシストコンボ3。SAゲージ3本 / 3本未満 / バーンアウト状態で内容が分かれるようになった。

## スクラッパー(後ろ投げ)

- [2024.05](../../patch-notes/battle-change/202405.md#L111) 画面端を背負った状態でヒットさせた後の間合いを遠くした。

## 立ち中K

- [2024.05](../../patch-notes/battle-change/202405.md#L112) 攻撃発生 7F → 8F、硬直 20F → 19F。

## 立ち強P

- [2024.05](../../patch-notes/battle-change/202405.md#L113) ヒット時の硬直差 -1F → +1F。ヒット時の押し合い判定を上方向に拡大し、空中ヒット時に位置を入れ替わりにくくした。

## 立ち強K

- [2024.05](../../patch-notes/battle-change/202405.md#L114) 攻撃持続 6F → 7F、硬直 17F → 16F。攻撃持続1〜2Fの前方への攻撃判定を縮小。攻撃持続の最終フレームをガードさせた際にカメラの揺れを追加し、ルーク側が有利な状況を分かりやすくした。

## しゃがみ弱P

- [2024.05](../../patch-notes/battle-change/202405.md#L115) 前方への攻撃判定を縮小。

## しゃがみ中K

- [2024.05](../../patch-notes/battle-change/202405.md#L117) 空振り時のみ、19〜29Fの体部分のやられ判定を前方に拡大。

## しゃがみ強P

- [2024.05](../../patch-notes/battle-change/202405.md#L118) **コンボ補正 10% → 15%。** 真上付近の相手に当たりづらくなるよう攻撃判定を縮小、攻撃持続1F目の攻撃判定を前方に拡大、動作7〜8F目の上半身のやられ判定を拡大。動作の見た目にあわせてキャラクターの中心軸が移動するようにした(必殺技キャンセル時に若干前に出る、ジャンプに対してめくられやすくなる等の影響がある)。

## ジャンプ強P

- [2024.05](../../patch-notes/battle-change/202405.md#L119) 動作9F目からやられ判定を下方向に拡大。拡大した部分は飛び道具無敵。

## ジャンプ強K

- [2024.05](../../patch-notes/battle-change/202405.md#L120) 動作10F目からやられ判定を下方向に拡大。拡大した部分は飛び道具無敵。

## アウトローキック(←+強K)

- [2024.05](../../patch-notes/battle-change/202405.md#L121) パニッシュカウンター時の硬直差 19F → 17F、パニッシュカウンター時のヒットバックを拡大。

## ノーズブレイカー(しゃがみ中K＞↓+強P)

- [2024.05](../../patch-notes/battle-change/202405.md#L122) クラシック操作のみ、強Kとの同時押しでは2段目が発動しないようにした。

## フェイタルショット(↓↘→+PP＞PP)

- [2024.05](../../patch-notes/battle-change/202405.md#L123) ダメージ 700 → 1000、SAゲージ増加量 400 → 1000、パニッシュカウンター時のドライブゲージ減少量 2000 → 7000。

## フラッシュナックル(↓↙←+P)

- [2024.05](../../patch-notes/battle-change/202405.md#L124) 中版。発動後に連打していた場合にホールド版が暴発しにくくなるようにした。
- [2024.05](../../patch-notes/battle-change/202405.md#L125) 中版ホールド。アーマーに対してヒット時に硬直が4F短縮されるようにした。
- [2024.05](../../patch-notes/battle-change/202405.md#L126) 強版のジャスト/ホールド。ヒット時のダウン時間を1F増加。
- [2024.05](../../patch-notes/battle-change/202405.md#L127) OD版。ヒット時のダウン時間を10F増加。

## DDT(↓↙←+PP＞PP)

- [2024.05](../../patch-notes/battle-change/202405.md#L128) ダメージ 2000 → 2500、SAゲージ増加量 1500 → 3000。

## 【SA3/CA】ペイルライダー

- [2024.05](../../patch-notes/battle-change/202405.md#L130) コンボ中の相手にのみヒットする攻撃判定を上方向に拡大。遠距離で発動した際に無敵時間が延長されないようにした。

## ドライブインパクト

- [2023.09.27](../../patch-notes/battle-change/20230927.md#L27) 特定状況下でヒット演出が発生した際に、相手にダメージが入らないことがある不具合を修正。
